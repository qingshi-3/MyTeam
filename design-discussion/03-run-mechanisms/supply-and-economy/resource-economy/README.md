# R09 资源经济

进程状态与当前讨论点见 [总览](../../../roadmap.md)，不在此重复维护。

## 决策边界

- 要决定：资源有哪些用途和竞争关系、如何获取/留存/消耗，经济引擎在哪些窗口生效。
- 不涉及：不照搬 PvP 利息；不提前强加新货币；具体内容强度另验。
- 前置或协作依赖：G03、R02、R05；与 R07、R08 共同形成一套经济，不互相等待全部完成。
- 本议题期望产出：统一资源流与机会成本；后续再校准价格/收益。
