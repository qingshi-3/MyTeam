# R09 资源经济

进程状态与当前讨论点见 [总览](../../../roadmap.md)，不在此重复维护。

## 决策边界

- 要决定：资源有哪些用途和竞争关系、如何获取/留存/消耗，经济引擎在哪些窗口生效。
- 不涉及：不照搬 PvP 利息；不提前强加新货币；具体内容强度另验。
- 前置或协作依赖：G03、R02、R05；与 R07、R08 共同形成一套经济，不互相等待全部完成。
- 本议题期望产出：统一资源流与机会成本；后续再校准价格/收益。

## 阅读与记录

先读 [讨论区约定](../../../README.md) 和 [跨议题问题](../../../05-integration/cross-topic-issues.md)，再读取与本题相关的现行权威。现行规则是本轮基线，修改建议只记录在讨论区。

[已有证据](evidence.md)保存刷新支付、留钱额外收益、普通装备退出、出售窗口与升级投入处理的全库筛查、原作过程、版本与缺口；[方案讨论](proposals.md)保存 R09-Q01／FC01–FC06、R09-Q02／SG01–SG06、R09-Q03／EX01–EX06、R09-Q04／SW01–SW02、R09-Q05／IR01–IR05 的完整比较、组合关系与推荐；[讨论决定](decisions.md)记录金币支付／限次／遗物减费、普通留存无息与特定内容收益，以及普通装备卖回／特殊交换的分工，遵循 [记录约定](../../../topic-records.md)。具体状态统一见总览，不把研究或推荐记为采用。

R08-D02 的每店有限刷新是前提，特殊资源候选的普通支付选择以后续 R09-D01 为准；不重开次数限制，也不立即填写价格／掉落表。购物额度与支付见 I31；培养材料替代／混合支付及回收见 I24，装备升级材料见 I21，共用金币不改写这些材料方向。进入本题不表示 R08 供给、拒领补偿或特殊服务已全部定完，不把免费战后奖励默认为可刷新。

G03-D02 已允许省钱过渡、关键节点转型；后续普通留存与特定内容生息的分工见 R09-D02，节奏和内容供给衔接见 I32。B09 经济位归具体体系，不将特殊经济内容改为所有阵容的必经步骤。

普通装备退出与既有免费换装、M05 升级材料／历史投入、R08 供给及特定交换机会的接口见 I33；普通卖回、非战斗出售窗口及不返材料／折金币的分工见 D03–D05。IR01–IR05 保留完整比较，具体计价／折损与 M05 尚未定妥的升级投入继续衔接，不把回收币种决定扩为历史记账算法或取消升级材料。M06 遗物退出、R03 英雄培养回退、R08 拒领补偿分别处理；不能由一种资产的退出权限推定其他资产同样适用。

普通收入与表现收益的阶段归属核对见 evidence／proposals 末节；实际收入、定价、供给与成长支付仍按各自依赖衔接，不把有待调节的参数都作为新的基础表决。伤亡造成的后续生命／可用性或共享资源损耗转 [R11](../../journey-and-pressure/attrition-and-recovery/README.md)；不以 PvP 连败经济反推本项目可在战败后继续。
