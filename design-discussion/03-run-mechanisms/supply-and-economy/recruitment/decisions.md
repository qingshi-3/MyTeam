# R07 招募机制：讨论决定

仅为讨论结论，不是现行玩法或实现权威。进程见 [总览](../../../roadmap.md)，历史机制比较与来源见 [方案讨论](proposals.md)和 [已有证据](evidence.md)。

## R07-D01：普通英雄不重复持有，遗物／事件可提供特殊复制

日期：2026-09-08。状态：**已确认但未合并**。适用范围：R07-Q01。同名指相同英雄内容身份，不是同职业、同羁绊或偶然相同的显示名称。用户表示更倾向不允许同一个，理由是没有三张一星升二星的机制、希望每个单位独立；遗物或事件可以提供复制能力，但普通情况不允许。

### 当前结论

- **普通制度采用 DR01：同一名册中，每个英雄只允许持有一份。** 已有英雄无论在场上还是后备，普通招募都不再取得第二份同名英雄；普通情况下不形成同名多份同时上场的阵容。限制针对英雄身份，不限制不同英雄共享职业或羁绊。
- **DR05 作为特殊内容方向保留可用：遗物或事件可以明确赋予复制能力。** 它是普通唯一规则的明确例外，不开放常规付费复制或普遍重复招募，也不预定初期一定制作复制内容。
- 理由是本项目培养采用材料和专属加强，不需要重复英雄作为合成材料；保持不同英雄的独立身份与阵容位置更符合用户意图。R02 的培养、R03 的受限整体回退保持，不新增同名合成。
- 原 Q01-P01 推荐 DR03 未采用；DR02／DR03／DR04 的普通重复制度继续保留比较，不作为当前规则。DR06 不重新进入通用培养方案。

### 普通资格与特殊复制边界

普通供给应基于已有持有排除可再次取得的同名英雄；后备持有同样占这一资格。单次候选内部去重、候选不足、刷新规则及退出后能否再次招募，留后续按实际流程明确，不将本决定推定为“本局历史上取得过一次就永远不能再取得”。退出再取得也不能暗中绕过 R03 培养回收门槛。

特殊复制的目标、持续范围、可部署资格、是否继承品阶／已选加强／装备，以及普通羁绊是否增加贡献，均留具体遗物／事件设计。不默认复制完整养成、不默认永久或临时，也不把普通唯一规则推成所有复制体都不能上场；效果须明确它提供的实际例外。

**本次没有采用 DR03 的普通同名贡献去重，也没有采用 DR04 的逐副本贡献。** 普通同名多份已被排除，无需为了不存在的常规情形再单独表决一条计数制度；特殊复制的贡献、成员身份和受益按具体效果与 M03 衔接。M03 的普通 1 点、开战定档、召唤／复活边界保持。

### 后续与恢复

Q01 的普通同名取得／持有／部署方向收束。R05 的节点招募与单次名额、R06 的内容组随机池和 G03 的适配推荐／其他体系空间保持；R07 后续先核对刷新、保留和候选纠偏中真正未决的部分，不重复表决唯一名册或材料培养。

I28 记录已拥有资格、候选不足及退出衔接，I16 继续记录特殊复制的贡献／成员／受益关系。此前局部代码观察不代表新唯一规则已经接入；统一整合时再核对实际候选与取得路径，本次不修改权威或实现。

本轮未新增研究，仅记录用户决定和跨题影响；未运行验证或制作复制内容。

## R07-D02：默认整批刷新并降低已见候选重现概率，其他刷新策略交给遗物

日期：2026-09-08。状态：**已确认但未合并**。适用范围：R07-Q02。用户明确“默认全刷”，RF02–RF06 应由遗物效果改变刷新策略，RF07 应为默认策略，以避免花资源刷新仍反复看到相同候选的挫败感。

### 当前结论

- **默认采用 RF01＋RF07：整批刷新，已见候选降低重现概率。** 普通刷新替换当前整批未取得英雄候选，不默认保留某个位置、比较新旧两批或回选历史候选。已见英雄在合法范围内仍有再次出现的可能。
- **RF07 是基础供给策略，不需要遗物才有。** 刷新应带来探索新选择的价值，减少资源花掉却反复看到相同结果的体验；这与 G03 的阵容适配推荐、同时保留其他体系方向共同作用，不用其中一层取代另一层。
- **RF02–RF06 归遗物的刷新策略设计空间**：RF02 保留指定候选／刷新其余，RF03 对刚拒绝项作明确排除，RF04 节点内已见不再出现，RF05 看新旧批次后选择，RF06 回选本节点历史候选。这些不是普通权限，也不是要求用户再选五种中的唯一一种。
- 原 Q02-P01 的默认 RF02＋RF03 推荐未采用。保留原比较和推荐历史，但后续不继续以 Agent 原初期排序限制用户已指定的遗物设计空间。

### 未定参数与内容边界

降权幅度、记忆窗口、恢复方式、是否跨节点及完全相同整批结果的处理尚未定；不把用户对重复刷新的不满擅自扩成默认每次所有候选必全新、永久零概率或 RF03／RF04 的硬排除。这里只明确默认软降权及减少无效重复的体验要求，具体生成规则后续按真实供给范围设计，不立即再问概率表。

RF02–RF06 可用于不同遗物，不代表初期全部制作、同时启用或全部按现有提案细节实现；各自的作用时点、使用条件、数量／次数、组合关系与代价随具体内容明确。它们仍只在原讨论的同节点语境作候选，不自动开放旧店回访或跨节点预约。

R07-D01 普通唯一英雄、R06 合法池、R05 资源刷新与单次招募名额保持。刷新策略不会自动增加可招募人数，已见降权不覆盖已持有资格排除；遗物保留候选也不等于已拥有英雄。候选不足与完全无法生成有效变化的处理仍需生成／经济规则衔接，不因本次确认默认补偿货币或凭空扩大合法池。

### 后续与恢复

Q02 的基础刷新和遗物分工收束。I29 衔接软降权、既定适配推荐、合法池及遗物例外；R07 后续先判断剩余事项是否真正需要通用制度决定，数值、效果细节留具体供给／经济／内容，不重复表决 RF02–RF06 或不断细问降权参数。

本轮没有新调研，仅记录用户决定；未修改现行权威、研究原库或实现，也未验证实际刷新体验。
