# R08 商店与奖励

进程状态与当前讨论点见 [总览](../../../roadmap.md)，不在此重复维护。

## 决策边界

- 要决定：购物与奖励选择如何组织、可重复购买与一次机会怎样区分、如何给替代价值。
- 不涉及：不决定全部货币体系或具体掉落物；已有原子提交不是待讨论玩法。
- 前置或协作依赖：M05、M06、R06；与 R07、R09 校核
- 本议题期望产出：非招募选择的结构、供给节奏和操作边界。
