## R06-D01：暂按内容组随机开放，并保留公共功能英雄

日期：2026-09-08。状态：**已确认但未合并，先确定大逻辑**。适用范围：R06-Q01 的英雄局级可用集合。用户对 CP01 推荐回应：“同意 暂时按这个大逻辑走吧”。

### 当前方向

- **采用 CP01 的大逻辑**：每局按可组合的内容组随机确定可用英雄范围，另保留必要的公共功能英雄候选。它限定本局招募资格，不代表将选中组的英雄直接发给玩家。
- 玩家继续按 G03-D02 从随机候选起步，随实际获得的英雄、装备和遗物逐渐定向；不增加开局先选定阵营或手编招募名单的常规步骤。
- 在本局合法英雄池内，继续执行已定的阵容适配推荐，同时提供其他体系的选择空间。合法集合与某次出现概率分开，不能越推荐越封闭，也不因属于本局池就保证招募到指定英雄。
- R05-D01 的普通容量默认开放、节点取得英雄、商店／兵营付资源刷新及单次招募名额方向保持。本次只选择池结构，不重开人口增长或确定招募参数。

### 暂不细化的范围

“暂时按大逻辑”不等于批准所有提案细节：抽取几组、每组几人、按哪个分类分组、多标签英雄入池规则、公共英雄名单和比例、组间关键机制连接仍需实际内容校核。组不必与单一羁绊或互斥阵营一一对应，不直接复制原作五神系数字。

CP03 预制完整池与 CP06 部分高费子池继续保留比较，未同时采用为基础制度；CP04／CP05 不重开已定开局方向。CP07 阶段供给、CP08 特殊改池按原归属留后续，不因此次确认增加通用付费禁用或保证全部特殊遗物初期制作。

可查看本局英雄名单、区分整局排除和后续开放仍保留为 Agent 的信息建议；本次主要确认池的大逻辑，不把具体公开时点／内容／界面强行记成用户逐项批准。装备／遗物是否按英雄池过滤也未决定，不因某英雄组缺席就删除所有同主题通用内容。

### 依赖与恢复

I27 继续跟踪多标签、关键机制／羁绊可达性、专用装备遗物和 R02 类别材料的适用对象；可达性校核不等于保证所有最高档羁绊或核心到手。相关问题在具体内容与供给设计中明确，有实质冲突时回看，不为补全数字继续逐项表决。

R06 的英雄池大逻辑已足够衔接 R07 招募机制；其余依赖保留，不宣称所有内容池设计结束或已经实现。主线下一步先读取 R07 及 G03／R05／R06 的既有供给决定，选择真实未决招募子问题。

本轮没有新增调研，仅记录用户方向并更新恢复入口；未修改现行权威、研究原库或实现。
