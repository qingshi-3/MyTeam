# R06 每局内容池：方案讨论

本文件为讨论提案，不是现行权威。进程见 [总览](../../../roadmap.md)，原作证据与限制见 [已有证据](evidence.md)。最新方向见 [R06-D01](decisions.md)：暂按内容组随机开放＋公共功能英雄的大逻辑推进。

## R06-Q01：每局哪些英雄有资格出现，这个集合怎样确定

### 问题与已定边界

- 已有 [构筑框架](../../../../gameplay-design/combat-build-framework.md)确认每局内容变化方向，以缓解大池成型困难；筛选方法尚未定。本轮先讨论英雄的局级资格，不把装备／遗物也自动套用同一筛法。
- [G03-D02](../../../01-global-boundaries/run-rhythm/decisions.md)已定随机候选开局、前期容错、随关键装备／遗物逐渐定向；常规不通过开局选择预先锁定构筑范围。推荐应契合当前阵容，同时保留其他体系，不能越推荐越封闭。
- **可用集合、当前节点供给、这次候选权重是三层**。英雄被排除出本局与在本次刷新中没抽到不同；已定适配推荐不能让不在合法池里的英雄凭空出现，也不能代替局级池制度。
- [R05-D01](../../roster-and-growth/population/decisions.md)已定普通容量默认开放、实际人数随节点招募增长；部分战后选人、商店／兵营可付资源刷新且单次最多招募 x 名。此处不重新定人数、刷新费或名额，不恢复人口等级门槛。
- G03 的类别屏蔽遗物是后续候选；并未批准通用免费禁用或开局手动组池。下列相冲突的原作机制仍保留参考，明确归属，不要求重选已定开局方向。

### CP01：按阵营／体系整组随机开放

Gods vs Horrors 的已有 Guide／档案描述每局开放随机五种 mythology，加上 Neutral；Ladder 与 Casual 的下一组和调整权限不同，不能概括为所有模式可自由重抽。

玩家面对的是“本局有几组可组合的英雄”，在这些组之间逐渐探索。以组为单位比逐名抽英雄更容易保留同体系的供应者、输出核心和辅助连接；公共功能英雄可以补充阵营之外的需要。

**收益**：每局组合变化明显，池规模可控，不要求开局先选定自己玩什么。**代价**：整组缺席会排除一些喜欢的英雄；如果组本身过于单一，容易变成每局在几套固定答案中选。不能照搬五组数字，也不能把我们的所有羁绊都假设为互不重叠阵营。

项目若采用，需选择合适的筛选分类或内容组，并校核多标签英雄如何进入池、组间连接是否充足；“只要一个标签入选就带入英雄”或“所有标签必须入选”尚未定，不能凭实现习惯补上。

### CP02：逐名英雄随机排除／选入，并保护组合结构

Underlords 历史 Jail 每 24 小时禁用英雄。Valve 明确指出 Scrappy／Inventor 被过度惩罚，Assassin 却几乎不受影响，后改为按 tier／alliance 限制的每日 8–12 名及 Ace 约束；Jail 后来移除。玩家对变化价值与日常最优解的意见也有分歧。

这提供了“以单个英雄为抽样单位”的直接案例；改成每局抽样是项目迁移，原作是每日共享变化。

**收益**：变化比整组更细，可以出现同羁绊不同成员的构筑。**代价**：容易抽掉关键连接点，只留下有标签但难以成立的半套内容。需要保护重要功能与可达组合；只保证某标签还有若干英雄，不等于其玩法仍能运转。校核成本明显高于整组取舍。

### CP03：制作若干完整候选池，再按局选择一个

Super Auto Pets 有预设 Pack、Weekly 和 Custom 等池边界；Auto Brawl Chess 2024 的 Seasonal 模式把供给收窄到六个 Faction，每十四天轮换，以应对官方指出的内容过多／寻找升级困难。它们的周／赛季轮换不等于每局重新随机。

用于项目，可以预先组织数套可混搭的英雄池，每局系统选择一套；这是对池结构的迁移，不是原作已验证的逐局算法。每套不必对应唯一流派，可同时保留多个核心和跨体系连接。

**收益**：每个池可单独检查功能、羁绊和费用分布，初期内容配置与验证更可控。**代价**：池数量有限时重复感更明显；增加英雄可能需要调整多套池，人工维护成本随内容增加。若让玩家固定选同一池，会偏离每局随机探索，需要另论；本轮不推荐默认手选。

### CP04：玩家开局选择几个阵营，组合成本局池

Monster Train 用主阵营与盟友阵营组合本局卡池，两组分别提供资源、输出和生存等组件。它是相邻卡牌构筑参照，不是英雄自走棋同构规则；不能把主阵营 Champion 身份移植成不可替换主英雄。

**收益**：玩家控制跨体系组合，能有目的地尝试某两个机制。**代价**：构筑范围在开局前收窄，容易先选好计划再找零件。

**这与 G03-D02 的常规随机候选开局、逐渐定向有冲突，保留模式／后续参考，不重新提交为当前开局待选项。**

### CP05：玩家逐名编辑自己的招募池

Super Auto Pets 的 Custom Pack 可跨普通包组合已拥有内容；Update 44 为 Standard Custom 限制最多五个 super pets，Wild 保持不限制。官方说明跨包平衡困难且耗时，不能把无限自定义理解为无需成本的自由。

**收益**：细粒度表达偏好，减少永远不想见到的内容。**代价**：开局前增加一轮组池和研究；玩家可能筛出最稳定组合，局内随机性退化为在精简清单里找人；内容之间的组合维护成本也高。

这比 CP04 更细，且同样有预先锁定构筑的问题。保留沙盒／后续模式参照，不作为当前初期推荐，也不由已有“遗物可屏蔽类别”推导免费全名单编辑权。

### CP06：普通基础英雄广泛保留，只随机部分高费／稀有英雄

Auto Chess 2025-05 重做资料记录：每场有十名可用 Legendary，其中五名初始隐藏，并有首次发现奖励。这说明局级变化可以只作用于特定档级，而不是所有英雄；不推定该作全部普通内容永远固定。

用于项目，可让基本前排、功能位和低费连接较稳定，变化集中到部分高级核心。这不意味着低费不能当核心，R01 的费用与培养价值边界保持。

**收益**：底层构筑知识能反复使用，后期目标有变化，缺某一组导致基础功能不足的风险较小。**代价**：如果变化只影响少数高费英雄，前中期可能重复；也可能让玩家投入某方向后才发现终局目标不在池。

隐藏名单属于独立信息规则，不能因为参考此机制就自动采用。其资格、是否公开与缺失时是否有其他成长路线需分别判断。

### CP07：随本局进程／解锁逐步扩大当前可出现的集合

Skull Horde 的稀有度扩张会把新的专门单位加入供给池，玩家报告扩大池会稀释当前追求、增加刷新成本。Super Auto Pets 的档案也记录 tier 逐步加入更多候选；这里只借阶段供给结构，不照搬回合表或同名合成。

**收益**：早期少量内容更容易理解，后期逐渐开放新核心；主动解锁时还能权衡扩大选择与稀释当前池。**代价**：新内容不一定都是利好，玩家可能为了追某人拒绝扩池；若永久移除旧英雄，也会伤害后期补羁绊与转型。

**这是当前供给开放节奏，可以叠加 CP01／CP03／CP06；单独采用不一定产生每局不同的总集合。** 需要区分“本局永远不出现”和“当前阶段暂不可得”，具体时点归 R07／R08／R10。不恢复独立人口升级或假设容量决定招募档级。

### CP08：通过明确规则修正池，例如屏蔽类别或改变可用体系

Auto Chess 的 2025 规则有付费 Race／Class blocking；Gods vs Horrors 的 Relic 可改变 mythology／pool，并有排除不兼容选项的官方修复。后者完整 Relic 表和时点不足，不能推定所有改池都在局中随时发生，或一定替换整组阵营。

**收益**：玩家在看清阵容后有机会纠偏，不必开局决定所有偏好。**代价**：删池强度可能高于直观描述，还可能删掉自己后来需要的跨体系英雄；改池时必须区分候选资格和已经拥有的英雄，不能默认已拥有英雄被移除。

G03 已保留的“遗物屏蔽某类单位”属于这一空间，本轮不要求重新采用它。常规付费屏蔽、增加或替换可用组属于不同具体权限，未因此获批；它是基础池的补充，不需要变成每局必做的清理任务。

## 已定推荐与本轮池选择的关系

The Last Flame 的 Soft Ban／配方锁定与解锁层次用于处理内容稀释，是已有适配推荐的相关参照。改变权重不等于硬性排除；这里不再提交“推荐契合阵容还是完全随机”选择，也不把 Soft Ban 名称推定为某种已核实的零概率禁用算法。

无论采用哪种基础池，必须在其中保留其他体系的选择空间。某套羁绊能触发、某套玩法有关键连接、某次刷新真的出现关键英雄，仍是不同层次。保障组合可达不等于保证每局拿齐所有高档羁绊或指定核心。

## R06-Q01-P01：原 Agent 推荐，主方向已确认，细节保留

倾向 **CP01：以可组合的内容组随机组成每局英雄池，并保留必要公共功能候选**。这是候选池，不是开局让玩家选定阵容；在池内继续执行已确认的适配推荐＋其他体系供给。

若初期内容较少或跨标签难以自动筛选，CP03 可用若干人工校核的池承载同一体验，但这是不同的组织取舍，不提前算用户采用。CP06 则是“稳定底层、变化部分高级内容”的独立可行方向，不能因推荐 CP01 就隐藏。

同时建议开局能够查看本局可用英雄／分类，清楚区分已排除和后续阶段才开放；不要求玩家开局读完名单，也不隐藏一个追求目标永远不可得的事实。此为 Agent 的信息建议，未获用户确认。

选择结构后，再聚焦组划分、多标签和装备／遗物依赖的必要规则；不在本轮强行定抽几组、每组几人或承诺每个体系所有档位都可达。CP04／CP05 不重开已定开局方向，CP07／CP08 留供给和内容协作。当前只讨论，无原型、实现或体验验收。

## 用户回应：暂按大逻辑推进

2026-09-08 用户同意“暂时按这个大逻辑走”，记录 [R06-D01](decisions.md)。采用 CP01 的内容组随机开放＋公共功能英雄；池内沿用已定适配推荐和其他体系供给。抽组数量、分类／多标签、公共名单及装备遗物依赖留具体内容与供给校核，信息建议不扩成已批准的完整公开规则。CP03／CP06 等不自动同时采用，原比较保留；主线衔接 R07。
