# R12 敌情预告与准备

进程状态与当前讨论点见 [总览](../../../roadmap.md)，不在此重复维护。

## 决策边界

- 要决定：提前展示哪些敌人/地形/Boss 机制、信息精度和预告后的调整窗口。
- 不涉及：不默认公开全部数值或行动；实际换人权限引用 G02/R04。
- 前置或协作依赖：G02、M02、R10
- 本议题期望产出：信息政策与可到达的应对窗口。

## 阅读与记录

先读 [讨论区约定](../../../README.md) 和 [跨议题问题](../../../05-integration/cross-topic-issues.md)，再读取与本题相关的现行权威。现行规则是本轮基线，修改建议只记录在讨论区。

[讨论决定](decisions.md)保存用户确认及适用范围；[已有证据](evidence.md)保存全库检索、公开时点／粒度、原作与项目推演边界及现行预览核对；[方案讨论](proposals.md)保存 Q01／PV01–PV08 的完整做法、取舍、推荐与回应。遵循 [记录约定](../../../topic-records.md)，不把研究或推荐当决定。

首题处理会影响准备方向的关键敌情应在什么选择之前公开。战前可看敌阵、地形与不限时调整已有资产已有基线，用户选择及剩余细节以讨论决定为准。R10 外层形式保持开放，不先规定固定层数；战报／日志、局外图鉴和具体反制供给分别沿 I09／R14／相关机制衔接，不混为一套全局信息系统。
