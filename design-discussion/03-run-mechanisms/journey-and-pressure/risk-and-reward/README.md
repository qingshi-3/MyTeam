# R13 自选风险收益

进程状态与当前讨论点见 [总览](../../../roadmap.md)，不在此重复维护。

## 决策边界

- 要决定：主动承担什么额外危险、得到什么收益、作用持续多久、如何预告和选择。
- 不涉及：不与普通难度递增混淆，不默认独立风险货币。
- 前置或协作依赖：R09、R10、R11、R12
- 本议题期望产出：自选风险机制与收益/恢复边界。
