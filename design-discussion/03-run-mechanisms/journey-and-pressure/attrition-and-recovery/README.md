# R11 跨战损耗与恢复

进程状态与当前讨论点见 [总览](../../../roadmap.md)，不在此重复维护。

## 决策边界

- 要决定：生命、阵亡与恢复机会如何影响路线和连续作战，哪些状态保留或重置。
- 不涉及：不新增未经确认的永久死亡、伤病或人力系统。
- 前置或协作依赖：M01、R04、R10
- 本议题期望产出：损耗/恢复闭环和既有失败规则的关系。

## 阅读与记录

先读 [讨论区约定](../../../README.md) 和 [跨议题问题](../../../05-integration/cross-topic-issues.md)，再读取与本题相关的现行权威。现行规则是本轮基线，修改建议只记录在讨论区。

[讨论决定](decisions.md)保存用户确认及适用范围；[已有证据](evidence.md)保存全库筛查、原作恢复／损耗归属、版本缺口及现行跨战生命的只读核对；[方案讨论](proposals.md)保存 Q01／AR01–AR08 的完整比较、组合关系、推荐与回应。遵循 [记录约定](../../../topic-records.md)，不能把研究或现有代码作为新决定。

首题只处理获胜后的英雄生命、阵亡可用性与损耗落点；战败／超时终局、每战法力起始值和临时召唤归属仍按现行基线。G01 的伤亡材料沿 I08 在本题核对，G03 的前期容错、自由准备及 R04 有限后备作为依赖；R09 已定出售／材料回收不延伸为伤亡补偿。R10 为并行外层讨论，本题不替它选择路线形式；恢复节点用途与具体内容的跨战效果分别沿所属议题衔接，不由基础生命恢复政策自动决定。
