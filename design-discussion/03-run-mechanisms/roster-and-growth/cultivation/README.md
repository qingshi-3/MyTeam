# R02 英雄培养

进程状态与当前讨论点见 [总览](../../../roadmap.md)，不在此重复维护。

## 决策边界

- 要决定：投入哪些资源、改变哪些能力，成长上限与核心/功能位投入如何安排。
- 不涉及：不默认全员融合、进化或科技树；回收规则归 R03。
- 前置或协作依赖：M01、G03；参考 R01
- 本议题期望产出：培养项、投入归属和成长过程。
