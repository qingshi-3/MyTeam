# R03 替换与培养回收

进程状态与当前讨论点见 [总览](../../../roadmap.md)，不在此重复维护。

## 决策边界

- 要决定：哪些投入保留、转移、回收或损失，以及触发窗口和循环利用限制。
- 不涉及：不把稀有蒸馏当常规回收；不重开既有装备免费转移。
- 前置或协作依赖：R02、M05；与 R04 校核
- 本议题期望产出：可解释的替换事务和成本边界，最后才定比例。
