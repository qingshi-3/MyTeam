# R03 替换与培养回收

进程状态与当前讨论点见 [总览](../../../roadmap.md)，不在此重复维护。

## 决策边界

- 要决定：哪些投入保留、转移、回收或损失，以及触发窗口和循环利用限制。
- 不涉及：不把稀有蒸馏当常规回收；不重开既有装备免费转移。
- 前置或协作依赖：R02、M05；与 R04 校核
- 本议题期望产出：可解释的替换事务和成本边界，最后才定比例。

## 阅读与记录

先读 [讨论区约定](../../../README.md) 和 [跨议题问题](../../../05-integration/cross-topic-issues.md)，再读取与本题相关的现行权威。现行规则是本轮基线，修改建议只记录在讨论区。

- [已有证据](evidence.md)：Q01／RC01–RC05 比较培养价值返回原材料、通用资源、英雄类别材料、直接移交或经济货币；区分原作退出收入与本项目退款方案。
- [方案讨论](proposals.md)：Q01-P01 及用户回应，保留不同返回形式的取舍。
- [用户决定](decisions.md)：D01 采用 RC01，折损留实际体验；D02 采用 RT01＋RT06＋RT07，保留英雄、整份回退，以服务／物品提供实际门槛，精细回退仅保留交互条件成立后的可能；D03 采用 RE01＋RE04，明确分支可重选、随机成长重抽。
- [Q02 操作与窗口](evidence.md)：RT01–RT07 分别比较保留重置、局部撤回、退出／替换结算，以及常规战前、服务或物品提供机会；不是互斥套餐。
- [Q02-P01 与用户回应](proposals.md)：保留原推荐；用户改选 RT01＋RT06＋RT07，不采用无条件无门槛的常规战前回退，避免游玩负担。
- [Q03 再培养选择](evidence.md)：RE01–RE05 区分明确分支重选、原结果、原候选、新候选及保留旧选项；固定路线不新增表决。
- [Q03-P01](proposals.md)：D03 已采用明确分支可重选、随机节点按合法池重抽，沿用已有服务／物品门槛；保留原推荐及用户回应。
- 前提见 [R02-D01–D03](../cultivation/decisions.md)：机制升阶、通用与类别材料混合支付。具体类别及双类别资格尚未定，不妨碍先比较返回形式；不能用 R03 自动补定材料规则。
