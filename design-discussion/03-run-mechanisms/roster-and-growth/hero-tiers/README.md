# R01 英雄分级

进程状态与当前讨论点见 [总览](../../../roadmap.md)，不在此重复维护。

## 决策边界

- 要决定：是否分级；若采用，获得阶段、职责和复杂度怎样体现。
- 不涉及：不混同稀有度、培养等级和升星，不改变每英雄一人口。
- 前置或协作依赖：M01、G03
- 本议题期望产出：分级采用与否及其规则；具体名单不在本议题。
