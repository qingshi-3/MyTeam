## 决策边界

- 要决定：后备容量、满员处理、换入换出窗口及培养追赶需求。
- 不涉及：不默认后备贡献场上羁绊，不要求培养第二支完整队伍。
- 前置或协作依赖：M01、G02；与 R03、R05 校核
- 本议题期望产出：后备与上场的交换规则和名册限制。
