# R05 人口成长

进程状态与当前讨论点见 [总览](../../../roadmap.md)，不在此重复维护。

## 决策边界

- 要处理：普通部署容量与实际取得英雄的关系、初始名册及招募节奏接口；最新方向以 [讨论决定](decisions.md)为准，不沿旧问题默认增加独立人口升级。
- 不涉及：不重新定义已确认的一人口/英雄及 10/18；临时单位容量先按 M02 核对。
- 前置或协作依赖：M02、G03；与 R04 校核
- 本议题期望产出：人口成长与供给接口；具体数量仍需决定后才记录。
