## 成型结构

职业提供战斗方式：护卫保护、斗士承伤反击、射手连续命中、突袭者收割、术士施法、祝祷者支援、统御者召唤。体系提供可跨职业读取的事件：寒意、棘毒、余烬、真实死亡、护盾、低血与法力施法。相同职业因此可以服务不同体系，同一体系也需要不同职责。

分档不是统一百分比递增：霜羽从减速进入冻结及传播，棘毒从持续输出进入转移及压制，构装从开场防护进入破盾反击及修补。数值档仍有意义，但应通过出手、存活或施法阈值形成可感知收益，不能把文字机制更多等同于强度更合理。高档继承低档机制，同参数替换不相加。

35名普通双轴角色、7名双体系桥接、3名双职业桥接、4名单轴角色。最高普通人口10沿既有讨论方向，桥接角色最多3标签，没有双职业兼双体系的四标签万能位。每条最高档均有2～4名候选余量；纯标签组合有15～70种最高档子集，这只说明非唯一名单，不代表这些组合都有合理职责或同等战力。

以下是可成立的连接例子，不是推荐固定配方，也不是模拟结果：

- 七人霜毒：MX01／03／05／36／06／07／10，形成4霜羽＋4棘毒及2护卫／2射手／2祝祷者；拿不到桥接MX36时，八人MX01／02／03／05／06／07／09／10也能达到两体系4档。
- 六人混合射手：MX03／23／32／48／01／21，形成4射手＋2霜羽＋2构装＋2护卫，说明无体系单位也有职业连接价值。
- 六人星辉术士：MX04／09／14／33／31／34，形成4术士＋3星辉，跨三个其他体系取施法核心。
- 六人亡契召唤：MX20／16／19／39／25／15，形成4亡契＋3统御者＋2护卫＋2构装，有召唤源、防护与合法亡语读取者。

## 查缺补漏与后续验证

24个位置标为候选改造，25个标为需补角色。候选改造也需重设接口、标签或技能，**没有将任何现有英雄标为直接完成**。同一HC仅有一个优先身份映射；其他位置只能参考机制，具体角色与素材另配。未被映射的现有英雄保留原状态，不代表删除、降级或开放保留库。玩家／敌方资源隔离继续保持，未来实现可以复用组件与素材，不能共享可变战斗状态。

术士、突袭者各只有两名T1／T2入口，虽能启动首档，早期供给仍较窄；桥接位集中于T3／T4，不能提前计入普通起步战力。I13／I24／I27／I35的成型时点、招募供给、成长与开放池依赖继续保留；本表数量不等于每局拿得到。

下一步需将候选的基础预算、技能周期与羁绊收益分开标定，在相同人口／投入下比较散搭、浅羁绊、深羁绊、跨轴混搭和关键位替换，并在多敌阵与站位下记录每单位有效输出、承伤、治疗／过量、护盾、控制并集、施法次数及首次施法。先检查体系是否稳定运作，再调阶段胜负门槛；不能直接拿旧运行资源冒充这49个设计位的模拟。
