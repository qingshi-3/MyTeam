## V1S01 岩座巨龙——特殊玩家单位，原索引317

参考云顶S7.5泰拉的三个保护地格与防御参与伤害的地震。原机制见[Riot介绍](https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/uncharted-realms-gameplay-overview/)。本项目采用1人口、统一防御，原龙神人口和三计数不带入。

| 属性 | 首轮值 |
| --- | --- |
| 生命 / 攻击 / 攻速 / 防御 | 1300 / 70 / 0.55 / 9 |
| 法强 / 射程 / 移速 / 身体半径 | 100 / 1格 / 1.6格每秒 / 0.45格 |
| 初始蓝 / 上限蓝 / 暴击 | 40 / 100 / 25%，倍率1.5 |
| 取得 | 高级升阶发现的特殊候选，最多持有1名；不是每局保证赠送 |
| 升阶收益 | 留空，基础技能与特殊能力从取得时即完整存在 |

**岩座守护（自身被动能力）：** 整备时选择3个不同的合法部署位置，在战斗开始时，站在这些位置的常驻友军各获得20%伤害减免，包括巨龙自己也可。受益者移动后保留，巨龙死亡后失效；返场不会重新授予已经错过的资格。与其他减伤乘算，同一来源不重复。未摆人的位置浪费本次名额，复制品或战中召唤物不能补领。三个位置在预览中直接显示，改变阵容时可免费重新选。

**岩震（主动）：** 成功启动后蓄势0.7秒，随后在1.5秒内连续震地3次，每次对自身2格内敌人造成`0.7A＋8D`普通伤害。完整完成后获得4防御，持续6秒；该加成不叠层。每次震地独立读取当时防御，硬控取消未发生的震地。技能不另附长眩晕，不靠无限控制保证自己输出。

价值在于花一个不贡献羁绊的位置，保护三个已经成型的关键角色。生命/防御装备既提高承伤，也通过D提高地震输出；它不是所有阵容都必须加入的免费保护。可以代替阵容中的第六羁绊位，代价需要在羁绊预览里看见。原作保护格和项目失效条件分开；20%和主人死亡失效均为项目参数。

## V1B01 创械监工——Boss，原索引398

参考S9黑默丁格可独立布置、选择升级的炮台机制，原作见[Riot介绍](https://teamfighttactics.leagueoflegends.com/en-us/news/game-updates/runeterra-reforged-gameplay-overview/)。这里设计成第二阶段Boss候选，以“先拆炮台还是突入本体”为战斗选择；没有把原作商店升级搬成战中抽奖。

| 本体属性 | 首轮值 |
| --- | --- |
| 生命 / 攻击 / 攻速 / 防御 | 4800 / 60 / 0.6 / 6 |
| 法强 / 射程 / 移速 / 身体半径 | 100 / 4格 / 1.5格每秒 / 0.4格 |
| 暴击 / 资源 | 无暴击；周期技能，不接英雄回蓝 |
| 初始部件 | 3座不同模块炮台，各占真实位置，可分别攻击和摧毁 |

炮台每座生命700、攻击45、防御4、基础普攻0.7次/秒、射程5、移速0、半径0.35、无法力无暴击，不继承本体面板；其普通射击受缴械和控制。炮台算临时部件，不贡献击杀装备的计数，不触发爆燃枪手“常驻敌人参与击杀”。该取舍必须写入敌情，不能把玩家不知道的临时身份藏起来。本体死亡即Boss胜利，剩余炮台退场。

| 部件 / 能力 | 完整行为 | 玩家可用的应对 |
| --- | --- | --- |
| 左侧贯穿炮台 | 除普通射击外，每6秒锁定最近敌人的方向，以1.2秒可见线形瞄准后发射长8格、宽0.6格的贯穿弹，对线内敌人各造成180普通伤害一次；地形阻断。 | 分散成不同射线、战术移动离开瞄准线，或集火拆炮台。 |
| 右侧爆破炮台 | 每7秒锁定射程内最密集的敌群中心，落点预告1.2秒后爆炸，半径1.5格、伤害200；预告完成后不追踪目标。 | 分散、提前移出落点；森林不能无脑挤成一堆。 |
| 后侧破甲炮台 | 普攻命中使目标防御降低25%，持续3秒；与其他同类百分比减防取最高。 | 刺客优先切入、牵引拆解可拉目标、换承伤者，或以射程集火。 |
| 本体：震荡手雷 | 首次第5秒，之后每8秒选择4格内生命比例最高的敌人，在其位置预告0.8秒后造成1.2格范围180伤害并眩晕0.6秒。 | 看到落点再移动；不持续追踪，更不专挑玩家最脆后排。 |
| 本体：重建 | 自首次炮台被毁起计时12秒；若本体存活且有空炮台原位置，蓄势2秒重建最早被毁的一座，恢复至350生命，每战最多成功1次。控制可暂停启动或中断蓄势，中断后本战不再重建。 | 保留一次控制、在倒计时内击杀本体，或继续拆低血量炮台；不是无限刷部件。 |

三个炮台与本体在开战前可查看。战场需有两条可走通的侧路，后排炮台周围保留可合法起跳的空位；本体、前排炮台不能完全封死入口。不得根据当前玩家阵容临时改变炮台模块或布置。普通冻结、眩晕、缴械各按效果作用，无新增全Boss免控。

专长不同但都保留方案：极地/圣盾可以延迟危险输出，射手能同时削弱多个炮台，换形/斗士可承担启动压力，森林可分散吸收普通射击，风暴在第8秒统一压血，刺客可越过炮台接近后排。本体与炮台的4800/700等生命尚未经历真实战斗验证；以上是可玩性的设计条件，不能据此宣称八种阵容都已能通关。
