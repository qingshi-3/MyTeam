## 候选不再是三张差不多的卡

普通招募的三个选项尽量来自不同职责，允许其中有当前不适合的转型/后期路线，不强行让每张卡都“推荐”。地图候选仍在开局确认时冻结；不能随着玩家当前阵容偷偷把已发现库存变成最需要的英雄。候选内容以英雄本身的成熟能力形成期待，界面显示现有羁绊变化只是帮助判断。

具体对照（各单位都要在本局池中且未持有）：

| 场景 | 三选一示例 | 实际选择 |
| --- | --- | --- |
| 早期招募 | 雷爪熊 / 花灵 / 双枪游侠 | 承伤多目标控制 / 低蓝护盾控场 / 跳后排机动输出 |
| 中期升阶发现 | 裂地巨兽 / 暮鸦领主 / 爆燃枪手 | 变身开团 / 吸取续航 / 击杀后火力升级 |
| 后期升阶发现 | 冰晶灵 / 风暴古龙 / 岩座巨龙 | 区域持续伤害 / 长启动集中雷雨 / 三个主力的站位保护 |
| 遗物奖励 | 珠光莲花 / 战利品契约 / 复苏之风 | 转技能暴击 / 把击杀兑现装备 / 稳定第二轮血线 |

这四组三选一是价值对照样例，不承诺每局原样出现，也不把“高级发现只抽这三个”写死。供给阶段标识只用于候选范围，不允许通过升阶自动给所有英雄增伤。

## 每局池与有限取得

24名普通英雄是总内容包，不是每局全部可招募。首轮提案用四个20人池，每局冻结一个；各池都有多个成型方向，同时保留4名不同的缺席英雄。其作用是成套变化，不把被缺席的第六人挂成假目标。羁绊详情同时显示“本局自然可得人数”；达不到的高档明确标为本局不可自然达成，不编造补人承诺。

| 池 | 本局不加入的V1U成员 | 自然可完整达成的主方向 |
| --- | --- | --- |
| 霜枪 | 11、12、13、15 | 6极地、6射手；也能4刺客、4圣盾 |
| 林形 | 04、09、20、21 | 6森林、6换形；也能4圣盾 |
| 风袭 | 06、08、12、24 | 6元素、4刺客、4圣盾 |
| 坚阵 | 06、13、21、24 | 6斗士、4圣盾；可3森林、3换形混搭 |

开局6选2仍来自本局低阶候选，之后进入现行固定大陆。普通招募依地域低/中/高压力候选阶级，升阶发现仍按阶段使用基础/高级池，冻结3个不同未拥有身份；不足3个不收费、不升阶，不以装备/金币卡填英雄槽。V1S01可作为高级发现池的额外特殊候选，无羁绊，不算第21个普通成员。

生成固定库存时需要将两条主要方向的完整成员分配到相容的取得机会；同一个三选一节点内的两个成员不能同时当作“已保证能拿到”。接入前必须对开局选择、招募互斥和发现配方做组合可达检查，不能只检查总池含有六人。本轮只验证总池和示例阵容的成员存在，未把它说成全地图取得已证明。

按现行3阶段各6行动，玩家每阶段用2次招募、4次战斗/其他服务，是一条18行动的示例节奏：开局2人＋6次普通招募最多取得8个不同英雄，再用逐次取得的材料选择升阶发现以补核心或替补。升阶每次4材料，不能在开局预支全局总材料；每个时点仍检查未拥有候选与实际存量。该账本不假设一定清掉精英、不送免费的第十人，也未校准招募金币与各路线材料是否足够。人口仍沿正式规则增长，名册人数不等于部署人数。

研究/生产保留现行机制，不以这次内容表暗改；新成员的生产功能、金币开销与随机大陆固定库存配方仍须一并接入后验证。此处已明确设计目标和样例，尚未完成自然供给率、最差种子与完整战役平衡验收。
