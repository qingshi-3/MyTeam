# 全局遗物设计

状态：提案。32件遗物全部由局级规则持有，31件不指定具名羁绊，R23允许玩家选择一条羁绊；没有遗物写死英雄名单。

海克斯在这里转换为玩家持有的全局遗物。全局表示规则属于这一局，不表示每个单位无条件获得同样收益。阵容发生变化后持续规则作用于新的合格对象；开战一次性规则只在指定时刻执行。

每件唯一、不可叠持；不同遗物可组合，明确的同类去重见条目。品质只控制奖励机会成本，不要求每件效果做三个数字版本。没有设计图标。本稿不覆盖当前RL01至RL25的运行数据。

## 供给与奖励池

同一次遗物三选一来自同一品质，并在生成时提供不同取舍。常规池以即时战力/资源为主，强化池包含改变构筑与延迟兑现，珍奇池提供人口/复制/神器。品质并非已验证的强度排序；R04对快攻、R02对单Boss的差异应保留，不能自动筛掉所有暂时不适配的选项。

| 池 | 正式候选 | 测试与耗尽边界 |
| --- | --- | --- |
| standard_equipment | E01至E18 | 可配置单项；装备允许重复，背包满保留待领取。 |
| airdrop | E03/E05/E06/E07/E08/E10/E11/E13 | 排除已装备同名；按英雄身份和战斗实例冻结，排除经济/复活递归。 |
| artifact | E19至E22 | 三选一抽不同；少于3件显示真实数量；空池不得供给R11/R31。 |
| bounty_equipment | E01至E18 | R28读独立池；接线测试可指向1件现有装备，正式奖励不写死该件。 |
| elite_bonus | 本稿常规/强化，排除R10/R11/R12/R13/R22/R23/R24/R28/R29/R30/R31/R32 | 不从额外遗物再生额外遗物；空池预览0。 |
| egg_reward | R11/R22/R24 | 每件按当前资格检查；不足3件时显示真实数量，全部不合法时等值转为artifact池选择。此补偿只属于卵，不改普通奖励耗尽规则。 |
| trait_heart | T01至T14，必须有本局可获得原生成员 | 取得时选定，不允许回访改心；不包含T15至T18。 |

当前遗物与本稿的迁移建议：RL25保留为R28，RL05保留为R30，RL16并入R05；其他现有通用遗物仍保存在参考库，评审后按重叠/供给预算决定保留，不在这次设计任务中删除运行资源。经济计数、事件生成、池抽取与授予各自独立，所有奖励只能在同一结算事务中兑现一次。
