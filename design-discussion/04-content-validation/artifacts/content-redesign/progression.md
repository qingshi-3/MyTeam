# 供给 成长发现与阵容推演

范围提示（2026-10-04）：本页保留2026-10-03的历史候选稿或其检查结果；当前首版范围以[D73](../../decisions.md#23-d73首版八个羁绊与单体特殊能力归属)的八项选择为准，独有机制归Boss/特殊单位能力。下方名单、采用去向和通过的旧稿检查不代表当前方案已完成重设计。

状态：新内容提案。以下给出一套可检验的供给规格，不把当前大陆的作者配置视为永久产品规则。保留三阶段、每阶段6次行动、地图库存冻结、开局六选二、升阶付费冻结三选一和Boss失败终局的已定语义；具体候选、价格、奖励和人口增长是本稿新参数。

## 每局有哪些内容

总库40人分为一阶11、二阶14、三阶9、四阶6。四阶是特殊能力或高投入主力，不是所有属性都自动胜过低阶；所有英雄1人口。

每局从四种完整名录方案中等概率选一种：暂不出现星环、暂不出现血誓、暂不出现龙裔、暂不出现碧潮。分别开放34、35、36、35名英雄，其余内容包整体保留；四名独有英雄一直保留。该局名录在开局六选二草稿生成时固定并可查询，重载不会变。没有开放某阵营时，不生成该阵营之心或宣称该阵营可凑齐。

不随意删单个关键成员。铁契、亡契、霜庭在这四种方案里保留，是因为当前刺客只由三个成员横跨它们组成；直接删其中一组会让三刺客失去自然成型路径。星环缺席时，时裂行者仍能连接术师；血誓/碧潮缺席时，岩鳞的近战普攻形态仍可连接决斗。两名三标签成员的技能先成立，再承担这些连接，不继续填满职业矩阵。

这是控制池变化的一版保守提案，不宣称四种方案已带来足够重玩性；后续扩大库时仍需通过同样的成员可达检查。总库全部40人都能在至少一种方案的生成池中出现；本局池表示可能来源，不保证地图实际展示全部34至36人。地图真实候选、已经错过和仍可发现的资格要分别显示，不能把库内数量当作玩家当局必然能选的数量。

## 开局与普通招募

开局仍是六名不同英雄选二：从本局开放的六个阵营中随机取三个，各提供一名前排和一名能独立输出的起步成员。候选对为：星环H01/H03，铁契H07/H08，血誓H14/H13，亡契H18/H22，霜庭H25/H23，龙裔H28/H30，碧潮H33/H32。玩家可以跨组选择，没有强制成对领取。初始金币提案10；两名初始英雄免费。

普通招募地点每次提供三名不同英雄，选择一名并支付金币和该地点的一次行动。阶级价格为3/5/7/10金币。各区域候选权重沿当前60/40/0/0、30/40/30/0、0/20/45/35起算；地图生成时同时检查配方，不允许某个开放阵营只有理论概率却整图一个核心都没有。

六个招募地点的完整候选在确认开局队伍时固定。每处三槽分别承担：该地点标识的阵营推进、一个连接职业/功能位、另一阵营可转向的主力。槽位不直接显示为“补短板/转型”等设计术语，玩家看到的是完整英雄及其真实能力。三个候选不必都适合当前队伍，也不故意摆两张低价值陪衬。

生成后的全图审核条件：每个开放阵营至少2名不同低阶成员出现在普通招募或开局候选；至少1名该阵营三阶以下输出核心出现在普通招募或发现候选来源中；主要输出核心的替代者也在本局名录。开局已经显示但未选的人仍可在后续招募出现。地点的具体三人冻结，不因浏览、持有阵容或读档重抽；已拥有的现货按现行规则标明失效，不偷偷换货。

## 升阶后的三选一

升阶花4材料，每名英雄一次。每次有效非终局行动给1材料，前两次Boss胜利也作为各一次有效非终局战斗计入；终局Boss不给新的发现机会。取得当次新增的英雄不能追溯参加生产。连续18次行动和前2次Boss共20材料，理论上能升阶5次；提前挑战或失败终局会减少实际次数。这是机会预算，不承诺每局都能拿满。

第1阶段升阶发现使用本局开放的三阶英雄；第2、3阶段使用三阶和四阶。选择前用已拥有名录计算并展示三名不同候选，扣料/升阶/冻结候选一起保存；不足3名则不可支付。候选生成使用三个职责，但都在同一发现价值层：

1. 与升阶英雄共享阵营或职业、能直接提高当前核心能力的候选。
2. 与当前至少一名英雄共享羁绊、但承担不同职责的候选。
3. 可单独使用的控制、保护、经营或另一条主力方向。

按槽依次从满足条件的未拥有候选抽取并排除前槽身份；某槽为空先放宽共享条件，再从同阶全池补足，不降到一阶陪衬。当前不要求每名英雄绑定私有三张卡，避免将升阶操作、升阶收益与英雄发现强耦合。

具体示例（候选是生成例，不是每局固定结果）：

| 此时阵容 | 可出现的三选一 | 三个真实选择 |
| --- | --- | --- |
| 盾星卫＋回星术士，前排已够 | 群星主宰 / 星泉医师 / 霜鬃骑卫 | 换更长线的输出核心 / 保住第二轮施法 / 先解决对方后排接敌 |
| 壁垒＋迅刃＋双枪，装备已集中双枪 | 刃舞统领 / 暮月猎手 / 岩座泰坦（第2阶段） | 转近战连斩 / 补游侠清场且沿用射手装 / 保持主力并保护阵地 |
| 棺甲＋墓园＋骨弩，已有冥灯 | 创械大师 / 沙阵君王 / 吞宴巨兽（第2阶段） | 炮台补稳定火力 / 布置阻挡和推线 / 用闲置名册换长期前排 |

缺席内容包或已经拥有的人不参与抽选，上例必须按当局名录检查。三选一不保证“都能立即提升同等战力”，但每张要有可说清的选择理由。选择结果的强度需要试玩，不能因为写出三种职责就视为问题已经解决。

## 装备与遗物供给

普通战首次胜利基础金币6，精英8；Boss1/2分别10/12，Boss3结束征程。初始不直接给三件成装。普通战每区域预设两处携带普通装备三选一，精英固定给普通装备三选一加同品质遗物三选一；是否绕路打精英是有代价的选择。

第1次完成有效非终局行动后给一次常规遗物三选一，Boss1后给强化遗物三选一，Boss2后给珍奇遗物三选一；这三次让开局、成型和终局各有一个构筑拐点，不另收行动。普通精英遗物配额每阶段最多一次，第一阶段常规、后两阶段强化。预期不额外触发奖励时一局3至6件遗物，避免每个普通小节点都弹一轮。

地图基础遗物候选在开局确认时冻结；动态遗物生成（黑星、卵）在事件触发时冻结。延迟遗物仅在剩余阶段预算足够时可出现：耐心之卵需至少3次非终局行动；黑星需至少1个未战胜、仍可到达的精英；悬赏挑战需本阶段剩余行动至少1且存在可达精英。R22若人口已经18或找不到3名候选便不供给。

装备是独立领取组，不能把“新英雄、两件装备、一点金币”随意放在同一英雄三选一里。普通装备价格6；同一商店固定6件普通装备，其中至少2件输出、2件防守、1件启动/功能，其余1件随机；第一次成功购买耗一次行动，后续照现行规则只花钱。凡是额外装备奖励都使用明确池，绝不把测试装备写死到效果中。

## 碧潮奖励表

全队共享一份局内潮汐计数，只有实际参加本战的碧潮成员付费释放成功才累积；回响、连斩、复活入场不增加。单次付费战斗上限20/35避免无止境拖延，但普通败战也会保留已经取得的潮汐，败战重试要支付行动。Boss战也能积累，终局胜利只做结算展示。

## 人口 训练与有限资源账

人口按作者提案初始上限7，Boss1后上限+2，Boss2后+1，到常规10。人口和已有英雄数量分别展示；7上限并不等于开局给7人。常规后备容量暂拟4，总名册可持有人口上限+4；这是对尚未确定的后备容量的新提案。

本版英雄基础技能已完整，不附送“每轮给别人4%属性”的生产被动。旧工坊在新内容包如何迁移必须单独确认。本稿建议将地图营地原有恢复/8金币旁增加训练选择：消耗该次行动与6金币，在单个已拥有英雄原始生命+12%、原始攻击+12%、研究+4中选一。永久提升按原始面板线性相加，不乘已有培养；研究沿现有法术兑换与消费。如此经营内容有取得窗口和行动成本，也不要求战斗单位身上硬塞生产被动。没有采用本提案前，现行工坊规则不变。

## 验证压力与通过条件

本轮没有重做整套敌人名录，也未给旧Boss套新倍率。新包验证先用真实可准备的压力：少量高单发、密集小伤害、分散远程、贴身切后排、可打断长施法、持续治疗、群体盾。分别检验格挡/防御、范围伤害、牵引/刺客、保护位、控制时机、重伤、破盾；这些选择必须在交战前有敌情与整备窗口，不能临时针对玩家队伍生成克制敌人。

应记录实际施法次数、首个关键技能时刻、各来源伤害/盾/治疗、控制覆盖时间、召唤物存活与贡献、每次发现的三张候选、装备数、剩余行动和全局生命。先以2/4成员与替代核心验证基本玩法，再试极限叠加；不以固定满配10人阵容胜利证明自然供给成立。终局需同时出现“阵容成功运转的优势战”和要求调整的压力战，不把每场都做成硬克制考试。
