# 装备配套设计

状态：提案。18件普通装备与4件神器，用于验证完整阵容关系；不冒充已有运行装备。每英雄3槽，同名装备同一英雄最多1件，战前可免费转移。阶级不限制装备，同队不同英雄可穿同名。召唤物不直接穿装备，只接受明确继承。

普通装备单件商店价6金币；神器不进普通商店，来自R11/R31等明确奖励。普通与神器的机制强度不同，不混为同一次普通三选一。装备效果中未注明的加百分比同类相加，固定属性先加再算比例；详见总稿。

| 编号与名称 | 完整效果 | 用途与边界 |
| --- | --- | --- |
| E01 蓝晶护符 | 法强+15；法力上限降低10，最低20；不改变初始法力上限约束。 | 低蓝连续施法，H03/H05/H32/H36；无蓝单位无效。 |
| E02 回响长矛 | 攻击+10、初始法力+15；本人普通攻击额外回复5法力，技能攻击/额外箭不触发。 | 高蓝启动与第二次施法，H04/H06/H24/H31。 |
| E03 聚能冠 | 法强+45。 | 纯粹放大技能；低施法次数也有收益。 |
| E04 珠光法印 | 法强+20、暴击率+20个百分点；本人技能伤害允许暴击。 | 与R01重叠时转为暴击倍率+0.15；不是双倍技能暴击。 |
| E05 疾刃 | 攻速+15%；每次本人普通攻击命中再加4%攻速，最多10层，本战保留。 | H09/H15/H26持续输出；不从技能/额外箭叠层。 |
| E06 处刑之刃 | 攻击+20、暴击率+15个百分点；暴击倍率+0.25。 | 普攻与可暴击技能主力，不赋予技能暴击资格。 |

| E10 饮血刃 | 攻击+10；本人伤害实际削减敌方生命的18%转为自疗；范围伤害治疗效率为1/3。 | 近战主力续航；不计算盾和过量伤害。 |
| E11 破甲弩 | 攻速+15%；本人普通攻击使目标防御降低30%，持续4秒。 | 统一防御破甲取同类最高，不和别的百分比破甲相加。 |

| E13 远射镜 | 攻击+12、普攻射程+1格；本人的伤害按实际距离每格提高4%，最多20%。 | 站位换收益；近战装上也可远1格，不限制职业。 |
| E14 统御权杖 | 法强+20；本人召唤物伤害提高20%。 | 不作用于复制英雄或无所属者的遗物假人；不乘召唤物身上的技能系数两次。 |

上述装备名用于内容讨论。传统蓝量、攻击、暴击、吸血、复活等机制属于成熟装备语法；全部数值由本项目提案给定，不主张它们是原作某版本的精确复刻。神器池保留可配置性，初次接线可仅1件，但正式三选一必须使用其实际数量，不放虚构空卡。
