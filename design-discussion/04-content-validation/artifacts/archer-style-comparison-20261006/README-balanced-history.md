## 共同要求

- 同一女弓手：红色高马尾、金色头饰、金紫服甲、浅色反曲长弓。人物原始来源为 [f1_ranged 精灵表](../../../../assets/donor-units/f1_ranged/f1_ranged.png)，对应 `prototype_u03` 当前帧绑定。
- 服饰结构合理、细节有主次。保留成套甲片、剪裁层次和少量集中装饰，避免普通制服般的过度简化，也避免碎饰、长飘带和飞散发丝堆满画面。
- 衣褶解释动作和体积，头发成束，金属高光克制，背景支持主体。动态主要依靠人物发力、姿态、透视与构图。
- 此轮生成没有沿用旧立绘提示词。最初仅输入精灵表；中间密度修订用旧立绘的视觉识别特征配合精灵表重新设计，随后十版用新 DNF 试稿作服装参考，不将其姿势和上色规定为所有风格。
