## 稳定部分与仍会变化的部分

稳定部分是主流程功能、浏览／选择／提交的区别、取消与返回、资源和库存结果、只读阶段、保存失败的原状态保留。保持新征程生成新开局、继续恢复已有开局；法术开战消费，战后奖励组彼此独立，已有装备可穿戴／替换／转交／卸下。

本轮用独立无头浏览器检查交互稿，不操作用户桌面鼠标，不运行 Godot，不触碰正式存档。参考产品画布为 960×540；这沿用现有验收环境，不是产品分辨率要求。

首稿完成过 20 页的参考画布边界检查、18 项连续交互与状态检查，以及最后 5 项定向补验；当时没有 JavaScript 运行错误。当前修订见上方最新记录。已查看开局、单位三选一、选敌、法术和军团装备的渲染。军团装备页保留 15 个属性字段（初始法力与上限分开），选中装备后的规则／穿戴按钮也处于可见区域。窄会话预览只检查重排不横向溢出，不冒充 Godot 多分辨率验收。
