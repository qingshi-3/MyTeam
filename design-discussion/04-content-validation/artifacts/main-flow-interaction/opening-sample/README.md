## 本轮视觉处理

专用石厅背景建立前后空间，中央冷光与边缘暖火区分背景和卡牌。灰石卡框沿用用户认可稿的宽倒角、块面与凹槽构形，人物、框体、名称属性、选中状态分层。六张卡同屏，三项核心数值共用一块信息牌；阵营与职业轻量排在卡下。

卡牌、外框与立绘作为整体抬起并放大，表达悬停；局部边缘高亮与两枚石席位表达选择，不再叠加对号。选中后头像飞入席位，满两位时启程按钮点亮；取消、满额、详情、键盘选择与减弱动效保持可用。不添加操作解释段落，不用全卡闪亮代替状态；详情标志使用本地字符。

首次样板使用已有六名具备不同立绘的基础英雄：MX01／MX03／MX23／MX02／MX25／MX05。仍沿用现有内容的图像绑定；不为缺图的 MX21 错配其他人物，也不以同一立绘充当六名角色。此展示组合不定义正式抽取池。数值继续沿用交互稿的示例值，不成为平衡参数；完整规则与真实属性发布数据仍须在引擎接入时绑定。
