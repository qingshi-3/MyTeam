# G03 整局节奏：讨论决定

本文件仅记录讨论结论，不是现行玩法或实现权威。进程见 [总览](../../roadmap.md)，机制原文与稳定编号见 [证据](evidence.md)。

## G03-D01：战前自由整备，补强节奏随进程安排

日期：2026-09-06。状态：**已确认但未合并**。适用范围：G03-Q01 战斗与整备的交替。

### 用户结论

- **T05 不采用**：不采用回访旧商店、由玩家往返安排集中采购的探索循环。
- **T09 采用不限时准备**：战前没有现实倒计时，玩家可以充分思考，自由调整已有装备、站位和部署单位，包括上阵与替补的调整。初期战斗仍按 G02-D01 全自动进行。
- **TL01 不照搬固定每五回合**：奖励与整备机会应按游戏进程和节奏安排，不把固定五回合当设计依据。这不是禁止一切周期性奖励；具体间隔与阶段安排未定。
- **T01、T02、T03、T04、T06、T07、T08 保留**：用户认为这些机制目前看来兼容，保留供后续组合设计，不要求在 T01 与 T02 中二选一。保留不等于已决定全部加入，也不等于采用原作的数量、服务表、日历或经济系统。

### 适用边界与待定项

- 战前自由调整指使用已有资产，仍遵守所属装备、人口和合法部署等既有约束；不推出免费采购、免费治疗、无限后备或战中换装换人。
- T07 若用于某段挑战，限制的是取得新资源的补给机会，不能借此锁住已经确认的战前装备、站位与上阵调整。
- T08 仅保留日程机制的想法；不能以现实时间流逝催促战前阅读与思考。哪些游戏内行为推动日历，若采用时另行讨论。
- 不以本次保留断言所有机制的具体版本天然兼容。后续可按不同阶段、服务内容与开放范围组合；每战是否采购、集中服务包含什么、挑战段限制什么供给，分别在对应整局议题落实。
- Agent 原先推荐的“以 T02 为主”没有获得单独采纳，不作为本次结论。总局长、构筑成型时点和成长强度也未由本次决定。

### 理由与后续归属

用户明确要求保留战前思考和调整的自由，认为固定五回合没有充分依据，应由游戏进程和节奏决定；其余做法可以兼容，无需过早压成互斥方案。装备与后备调整窗口由 M05／R04 承接，成长和补强机会由 R05／R07／R08／R10／R11 细化，并与 R12 的敌情准备校核，跨题跟踪见 I12。

## G03-D02：宽容探索开局，随关键收获形成体系

日期：2026-09-06。状态：**已确认但未合并**。适用范围：G03-Q02 构筑成长过程。机制编号沿用 [B01–B11](evidence.md)。本条记录用户对 P01 的具体修正与选择，不是原提案整体照单采用。

### 开局与前期：允许为未来体系投入

- **B01 不作为常规方向**：不通过开局选择预先锁定构筑范围。用户更倾向于由系统随机提供候选，玩家从中选择若干英雄组成开局阵容；候选数、选择数、选择批次与刷新规则未定。
- 前期战斗压力减小，给予充分容错。玩家可以为可能形成的体系拿英雄或组件，不必每次都为了眼前战力拿牌。这不等于保证任意选择都能过关；具体容错如何由敌人与供给实现留待后续。
- **B02 按用户修正采用**：在战斗推进、升级、奖励与新招募中，依据实际获得的关键装备、遗物等逐步确定阵容体系。借鉴《杀戮尖塔》的逐渐定向，不照搬攻略中“先解决眼前战斗”的压力要求。
- “早期已有可用组合”可以成立，但不能反过来要求玩家必须尽快凑出战力闭环；探索潜在体系也是有空间选择的前期玩法。

### 核心成长与换人

- **B03／B05／B06 可以同时存在**：小组合逐步补全、早期核心持续培养、阶段机会提供关键组件或方向变化可共存。不因此套用 Reborn、全员进化或固定阶段数量。
- **B04 允许**：玩家可以先节省资源、使用打工单位过渡，到关键节点再寻找其他核心并替换。这是允许的路线，不是每局必须换核心，也不据此确认利息、共享卡池或具体搜牌公式。

### B07：默认供给推荐应契合阵容，同时提供其他方向

- 系统随机发放单位、装备等候选时，默认应有倾向于契合玩家当前阵容的推荐机制。这是常规供给方向，不依赖先获得某件遗物才能发生。
- **同时必须提供其他体系的选择空间**，让玩家能探索新方向、转型或为未来准备。不能通用地做成“当前是什么，后面就全是什么”，避免供给越推荐越封闭。
- 本次没有采用 Guildrun 的职业升阶或职业池锁定系统；采用的是玩家所述的供给倾向与开放边界。当前阵容如何识别、是否读取后备和所持装备／遗物、契合度规则、其他体系的名额与出现频率、候选质量和概率均未定，不将“要给其他选择”弱化成无需落实的口号，也不先编每批固定配额。
- **遗物屏蔽某类单位：保留后续设计候选**。玩家可通过某些遗物效果主动屏蔽类别的想法已记录；具体类别、作用范围、代价、持续时间和是否可撤销待设计。它与默认的适配推荐是两层，不自动引入普遍免费禁选，也不是现在授权实现。

### B08／B09／B10 的归属

- **B08 伙伴系统：暂时不做，持保留意见**。这是酒馆的特殊独立系统，未来扩充内容可考虑；不列为初期成长保障的必需环节。
- **B09 经济位、B10 跨战积累：属于具体体系玩法**，不是全体阵容的通用成长流程。不要求每局先铺经济位或让所有单位永久叠属性；具体内容以后按其体系设计。

### B11：成型后的关键战斗与可选无尽

- 成型后应有若干场战斗让玩家充分体验构筑成果。敌人要耐揍，也要保留一定挑战，使成熟体系有发挥空间；这是关卡难度与数值节奏要落实的体验目标，具体场数、战斗时长、生命和伤害曲线未定。
- **支持成型后可选择继续无尽模式的后续方向**，用户以《小丑牌》作类比。这是用户想法的来源，不是本轮新增核验过的外部机制证据。
- 无尽不是初期重点，也不作为当前设计重点。核心体验放在**成型前的构筑过程，以及成型后的若干场关键战斗**；不以未来无尽替代主流程的体验。开放时点、退出／结算、奖励和难度增长均暂不展开。

### 影响与待定归属

- M01／R07 承接随机候选英雄开局；与现行起始英雄选择表述的待整合差异登记 I14。英雄平等名册身份、可替换与人口规则没有因此改变。
- M01／R01–R03 承接持续培养与可选换核；R06–R08 承接阵容适配、其他体系供给和关键组件可达性；M06 承接遗物屏蔽类别候选；R09 及具体内容承接 B09／B10。
- R10／R12 与后续内容检验承接宽容前期、成型后关键战斗及相应难度数值；跨题一致性统一跟踪 I13。暂缓伙伴与非重点无尽不作为当前讨论阻塞。
