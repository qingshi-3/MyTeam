# G03 整局节奏：方案讨论

## G03-Q01：常规整备与补强机会的节奏

状态：本子问题的边界已由 [G03-D01](decisions.md) 确认，未合并；其余机制保留组合空间，具体服务与频率归后续议题。以下保留原推荐及回应，不能将历史推荐视为用户决定。

本轮问题是哪些准备机会每战都有、哪些依赖进度或节点；具体路线组织归 R10，招募／商店／奖励和恢复规则归 R07／R08／R11。完整材料见 [T01–T09／TL01](evidence.md)。

### 已有边界

- 初期自动战斗，玩家的战斗策略主要在准备时表达；这不要求每次准备都购买新东西。
- 已有战前调整站位、替补上阵与免费转移装备。备用阵容和培养回收方向已定，具体容量和回收量未定，不在 G03 重新选择。
- 普通人口成长向十、明确投入可到十八继续有效，不通过引用 Astronarch 的阶段加人例子改动人口上限。
- 现行分区路线已有商店、招募、休息等节点。当前倾向接近 T02；比较是评议其体验节奏是否适合作为方向，不假装刚创造了这一结构。

### G03-Q01-P01：历史 Agent 推荐，未作为整套方案采用

建议以“每战基础整备＋沿途专门补强机会”为主（T02），保留阶段性较大调整的空间（T03／T04），不预设完整城镇或固定的 Boss 后人口奖励。

- 每场开战前，玩家能用已有英雄、装备与站位回应下一场；无需每场都完成一次购买／重抽才进入战斗。
- 普通战斗后的奖励承担小幅成长；完整采购、招募、恢复或深度培养主要通过相应机会获得。具体给什么、频率及是否某类战斗不给奖励，仍归后续节点／奖励规则。
- 较大调整机会可集中在阶段之间，既让玩家有期待，也使普通战斗有时间呈现刚完成的构筑变化。这里不强制全部重大成长只发生在章末。
- 当时建议准备时不设现实倒计时（参考 T09），让时间压力来自继续挑战前是否值得投入资源、能否撑到下一次补强，而不是读说明够不够快。不限时部分随后由 G03-D01 确认；所述资源压力并未因此成为必做系统。

收益：战斗、小幅成长和大调整有不同节拍，不必每战重复完整采购；战前布阵仍能持续发挥作用。代价：缺少某个新组件时未必马上能买到，后续 R10／R12 必须让重要补强机会和准备需求能相遇，不能靠本建议保证关键物品必出。

原提案将“每战固定补强，还是主要依赖沿途机会”列作主要待选差异。用户回应认为其余机制可兼容保留，因此不再要求 T01 与 T02 二选一，也不把“以 T02 为主”记为已采用。

### 用户回应后的组合边界

当前决定以 G03-D01 为准：T05 排除，T09 不限时，TL01 不照搬固定五回合，其余保留候选。每战开放某类服务、专门节点提供另一类服务、阶段里程碑安排较大补强，可以分层组织；这里只说明组合可能性，不预定一套服务表。T06 的共同选择池与 T08 的日程机制也仍需在实际使用范围内校核，保留不代表整套引入。

T07 的供给限制不能限制已有资产的战前调整；T08 不能变相增加现实准备倒计时。具体组合若产生冲突，应在对应议题展示实际冲突和取舍，不因清单标题不同先要求用户排除其中一项。

### 后续去向

Q01 不再等待逐项表决。在 R04／R05／R07／R08／R10／R11／R12 承接调整窗口、节奏与供给，日历或受限补给若实际采用，再讨论其结构影响；不继续推荐已排除的回访商店。下一次继续时先检查 G03 尚有哪些真正需要确定的全局成长预期，例如构筑如何随进程展开，不把具体节点和经济细则提前拉入。总局长、构筑成型时点和成长强度仍未定，不能据 Q01 已确认就宣布整个 G03 完成。

## G03-Q02：构筑从起步到成熟怎样展开

状态：用户已按 [G03-D02](decisions.md) 确认并修正成长方向，未合并。以下 P01 保留为历史建议；当前结论以 D02 为准，不是原提案整体采用。

### 问题与已有边界

本轮比较开局带多少方向、途中怎样确定核心、后期怎样继续成长，完整材料为 [B01–B11](evidence.md#g03-q02构筑从起步到成熟怎样展开)。不规定第几层／百分之几成型；少数核心投入、功能位／替补与培养回收沿用。研究时以现行起始英雄选择为基线；用户随后在 D02 指定随机候选中选若干英雄的方向，不能以旧基线要求用户重新选择。英雄仍可替换，B01 或 B08 不能成为恢复永久特殊主英雄的理由。

全局尚需明确的是玩家能期待怎样的成长过程，而不是先定商店赔率、升星算法或每层奖励。总局分钟数留待战斗与内容规模更明确时再校核；不能从研究游戏的时长和层数直接定我们的局长。

### G03-Q02-P01：历史 Agent 建议，用户已修正

建议以 **早期已有能运作的小组合，途中逐渐确定并补全方向，后期有足够机会使用成熟阵容** 为常规体验。

- 起始英雄给一个起点，实际所得仍能改变方向。B01 的强内容范围限制与 B07 的后续池绑定可以讨论，但不因为已有起始英雄就推定整局路线已锁定。
- B03 作为常规成长体验：没有终局关键件时也能形成阶段性打法，而不是前半局一直等待抽中开关。这里建议的是体验目标，不承诺某个核心、组件或完整队伍保底出现。
- B05 的持续培养与 B04 的后期换核可同时成立：早期核心应有可行的后期路线，玩家也可为新的机会转型。不要把强制晚期换核心做成所有队伍的毕业流程；现有回收和装备调整可减轻成本，但不能自动解决稀有组件可达性与剩余成长时间。
- B06 可以提供阶段支点，B07／B08 分别保留选择连续性与进度保障的比较价值。是否采用、通过何种载体表达，仍需用户意见和对应模型，不顺带引入通用进化、职业树或特权起始英雄。
- B09 的经济先行、B10 的逐战积累可提供不同发力曲线；不应成为每局必须先攒钱或必须早拿永久成长组件的单一路线。非羁绊行为构筑已确认，本建议没有把具体经济／击杀效果提升为普遍规则。
- B11 的重点是成型后留出实际运用时间。普通流程也可以做到；无尽只保留为一种承载方式，不能拿“以后有无尽”自动弥补主流程中刚成型就结束的问题。

收益：早期投入有价值，随机能带来改向，后期仍能享受已完成的配合。代价：需要内容与供给共同支持多条可行成长路径；前期不能只靠高运气开局过关，后期不能只剩少数必换终局单位，也不能以无限复利支撑所有长线挑战。这些是建议的体验约束，不是假称已经平衡或验证通过。

### 用户修正及后续归属

D02 将常规开局改为随机候选中选择若干英雄，明确前期容错应允许为潜在体系投入；不能再以“先保眼前战力”或“尽早凑出闭环”概括项目目标。逐步补全、持续培养、阶段关键机会和可选换核可以并存。

B07 不再是是否采用职业池绑定的待决问题：默认随机供给要有阵容适配倾向，同时提供其他体系选项，反对同类无限收窄。匹配算法、候选配比与主动屏蔽类别遗物的细节在 R06–R08／M06 处理；不可将用户要求偷换成只改界面推荐标记而不影响候选供给。

B08 暂缓、保留未来扩充，B09／B10 属具体体系内容；B11 是关卡难度与数值节奏的约束，不再把它包装成是否需要独立系统的选择。主流程以成型前和成型后的若干关键战斗为重点，可选无尽获后续方向支持，当前不展开。

Q02 已有体验约束，不继续要求逐项表决。M01／R07 承接开局选择，M01／R01–R03 承接成长与替换，R06–R09 承接供给和具体体系，R10／R12 承接前期容错及成熟阵容使用空间；关联 I13／I14。下次继续先核对 G03 阶段归属，若无真实全局缺口则进入 M01；不为凑问题回到固定局长、成型层数或暂缓的伙伴／无尽细则。

## G03-Q03：固定核心与关键装备会不会让每局重复

2026-09-19。状态：用户提出风险，以下为 Agent 分析与建议，尚未采用；不重开 D01／D02，不授权实现。用户以“极地拉面熊、火炮、羊刀”说明固定核心与关键装备的成型快感及重复忧虑；这里只使用该构筑结构作类比，未新增核验原作版本、技能或装备细则。

### 风险判断

固定核心和明确强配合可以带来识别、期待与精通。需要警惕的是：核心一旦选定，后续最优装备、队友、投入顺序和应对都固定，玩家只等待清单补齐。主动反复玩喜欢的体系与因其他选择明显吃亏而被迫重复，应分开评价。

单人环境没有其他玩家抢同一套组件或主动调整阵容的压力；若指定配方易于取得、过渡代价低、对多数遭遇都占优，硬玩同一套的风险较高。反过来，只降低关键件出现概率而保持唯一配方，可能把重复变成等待与落空，并没有增加有效决策。这是设计推断，未作玩家行为或平衡实测。

### 建议与取舍

1. **保持核心辨识度，让主要体系的配套存在不同完成方式。** 例如同一近战连击核心的输出环境，可以分别依赖射程装备、保护／控制队友或位移切入；启动可以依赖自身攻速成长或队友提供攻击窗口。不同方式须真实改变槽位、阵容位置、成长曲线和弱项，不能只是同一装备的几个低配替代。这里是假设样例，不代表相关内容已存在，也不要求每名英雄都有多条路线。
2. **保留少数精确组件组合的极限成型。** 精确配方仍可提供独特快感；主要常规体系应有值得继续玩的非完美版本，避免全库都成为缺一件就停摆的配方。不得把所有装备做成可互换同质品，也不默认取消关键装备。
3. **让核心之外的选择受实际收获与遭遇影响。** 长战成长、前期生存、群体覆盖、单体爆发和后排保护可以竞争投入；敌人提供不同压力，同一体系可通过不同功能位、装备或站位应对，不按敌人指定唯一解题阵容，不临时针对玩家生成硬克制，也不强迫每局换核。成型后保留若干场兑现机会，沿 D02。
4. **供给保留连续性与诱人的其他方向。** R06-D01 的变化池能减少每局都具备同一配方的机会，但不能单独解决池内选择固定。G03-D02 的契合推荐需要避免把早期选择放大成整局自动配送毕业清单，同时不撤回推荐方向或编造每批配额。其他方向必须有实际使用价值及可承担的转换成本，不能仅占一个无吸引力的候选位置。

### 下一步与关联

建议以一套具体核心做纸面检验：改变首个关键装备／遗物和已知敌情后，合理的队友、装备或投资选择是否改变；拿不到理想关键件时是否仍有有趣且可行的成长路线；抽到该件后是否仍有取舍。若所有情境都回到同一毕业表，优先检查内容配合、机会成本和收益优势，再考虑加大随机性。无需先增加通用系统、随机装备词条或英雄数量。

恢复时承接用户对上述风险与方向的反馈，不能把本轮建议写成已确认规则。关联 I13（成型过程）、I27（局级池与组件可达性）、I29（推荐与刷新）、M05（固定装备）、V01（英雄／装备／敌人内容检验）；既有材料培养、固定一主动一被动与装备固定定义保持。本轮仅更新讨论记录，无新增外部调研或运行验证。

### 用户补充：大装备池仍会收敛到同一收益链

2026-09-19。用户表示本项目大概率不走散件合成，倾向装备数量较多、直接取得成品的方向；这是当前倾向，不记为已经禁止所有合成。用户以其《将息之焰》游玩体验说明：英雄与装备很多，但反复采用叠满暴击→暴击供盾→盾超过生命值时提高生命值，再补虚无／攻击伤害便可通关；缺少盾成长时明显不够爽，同时指出大量每秒／每3秒触发的装备体验相似。以上为用户提供的体验证据，未独立核验版本、完整触发规则、难度或原作整体平衡；不据此断言所有可行阵容或无限／指数增长。

本反馈将重点由“指定配方易复刻”推进到“不同内容汇入同一条占优收益链”。前述同核配套分支仍可参考，但若不同分支最终都以同一套暴击／盾成长维持生存、靠时间累积，不能仅凭装备名称与伤害类型不同就算玩法差异。散件合成、降低指定件掉率或增加全库数量均不能单独解决这一层问题。

**Agent 分析（待讨论）：**

- 按用户描述，暴击投入同时带来伤害机会和供盾，供盾又带来成长；活得更久提供更多攻击及周期触发机会。若此链的启动代价与风险很低，且足以处理多数遭遇，独立防御／输出投入与其他成长路线会失去吸引力。生命是否再反馈盾量或伤害须看实际公式，不能擅自补成数学上的自我递增环。
- 当主要收益由通用装备自行完成，大量英雄可能只在攻击频率、存活能力或基础数值上区分，原生技能不再决定配套与战斗过程。组合连接多不等于有效玩法多；项目已有产生／读取／转换／兑现语法也需接受这一检查，不能因技术上可组合就视为体验充分。
- “每N秒”不是天然有问题：周期光环、波次或蓄力释放可以形成可见节奏。风险在于大量无条件周期收益只要求存活，令保命与拖时间成为普遍最优投入。换成“每次暴击”也未必解决；在满暴击、稳定普攻的条件下，它仍可能只是受攻击频率驱动的稳定产出，须结合选敌、范围、换目标、受击与主动循环判断真实差异。
- “其他路线也能通关”不足以回答用户的“不够爽”。需要分别比较同阶段／相近投入下的稳定性、启动速度、上限，以及成型后可见的爆发、连锁、覆盖、攻速或反击等兑现；不能只削弱用户喜欢的组合，让全部路线都缺乏高潮。

**后续内容建议（尚未采用）：** 保留强组合，让不同路线具有不同战斗过程和可见强势时刻；装备优先与英雄实际行为发生关系，通用数值与周期装备仍可作为基础内容。攻防／成长转换须检查槽位、组队、启动、作用范围、消耗或强势窗口的实际代价，但不把这些限制叠加成每件装备的模板，不默认全部设上限或取消自动成长。可对照的假设包括：依赖目标分布的弹射连锁、队友保护启动的范围重击、实际承压后兑现的反击；仅为比较思路，不是制作名单或已验证平衡。

### 用户构思：羁绊承担部分强力效果，保留阵容与英雄的差异
