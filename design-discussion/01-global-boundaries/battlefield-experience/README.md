## 决策边界

- 要决定：地图和多战线要让玩家做哪些有意义的取舍。
- 不涉及：不定具体地图、坐标、胜负目标或英雄技能。
- 前置或协作依赖：无；读取既有地图方向。
- 本议题期望产出：期望战术决策、反例和可观察的体验目标。
