# M01 单位／英雄模型：方案讨论

## M01-Q01：英雄自带哪些能力，哪些部分可以局内配置

状态：Q01 初期边界已按 [M01-D01](decisions.md) 确认，未合并。下文 P01 保留为历史建议，用户已收窄其范围，不作为整套已采用方案。

### 为什么先讨论这一项

英雄的招募价值、装备能改什么、被动怎样联动以及核心的成长空间，都依赖“英雄自己带什么、局内再配什么”。因此先明确能力构成与配置边界，再讨论施法资源和行动安排。属性公式、技能实例、招募算法与培养价格不作为本轮附带决定。

当前首批内容是每人一个自动满蓝技能，但议题 README 已明确不能把这个数量当作最终模型。初期无战中介入、距离接战、随机候选开局、核心／功能位分工等已定，全部作为前提。材料与稳定编号见 [H01–H12／HL01](evidence.md)。

### M01-Q01-P01：历史 Agent 建议，用户已收窄

建议常规英雄以 **可辨认的固有能力＋有边界的局内扩展** 为基础。看见一个英雄时应能理解它的主要用法，具体装备与附加效果再改变它在这一局的表现。

- **基础动作明确，功能不强制相同。** 现行已有攻击与治疗基础动作，不先要求每个英雄都进行伤害普攻。移动／射程等空间细则归 M02，不在这里重定。
- **固有能力允许自动施放与被动组合。** H03 的主动＋被动适合作为紧凑的常规内容起点，但不建议把“一主动一被动”变成所有英雄必须填满的表格。H01 的简单招牌角色、H02 的事件型角色也值得允许；纯被动或多自动技能是否进入初期尚待用户决定，不假装现行已经支持。
- **原生特色和附加效果分清。** H09 在本体行为上配置特性，可以与装备／遗物联动；若用户认可，应在 R02／M05／M06 再定取得来源、可替换范围和限制。它不是额外默认赠送一套免费培养系统。H04 的阶段解锁可以提供成长变化，但不能把功能位的基本用途都藏到高投入后。
- **不默认把所有英雄做成技能容器。** H05 的职业内多技能、H06 的额外法术、H07 的广泛跨职业装配、H10 的武器改整套动作仍完整列为比较。Agent 暂不推荐把 H07／H10 作为全体英雄的默认结构，原因是它们会把更多身份定义交给配置，也放大十人常规阵容下的阅读与管理量；不是因为技术不支持或用户已经否定。
- **H08 的随机个体特性单独判断。** 随机候选英雄已获确认，不等于同英雄还要额外随机天赋。若引入，需要考虑它是否增加有意义差异，还是只增加刷完美个体与比较文本的负担；不据此擅自采用通用洗词条。
- **H11／H12 按既有特殊内容范围容纳。** 特定英雄可换形态，特殊内容可做继承或进化；不重新要求全员走这类流程，也不将原作具体转移规则自动采用。

收益：英雄身份、招募判断和局内构筑各有作用，普通角色与复杂核心可在同一名册里共存。代价：原生与后加能力的归属需要清楚，过多能力会增加辨认和选项负担，过少又可能限制本体特色；“推荐紧凑”不等于已经决定槽数或把所有复杂度推给装备。

### 原待决边界与用户回应

原提案比较本体特色与配置自由度。用户已选择固定主动＋固定被动、初期本体不提供局内配置，暂不做随机个体属性／特性。因此不再推荐初期可变本体能力数量、纯被动／多主动变体或 H09 可教学特性；其他想法保存为后续参考，不逐项催促表决。

随机候选英雄已定，但同一英雄不额外随机一套个体属性；这与随机装备／遗物以及阵容适配供给分开。装备效果联动和培养方向仍有效，具体强度变化在后续模型说明，不能用本次“固定”推断全部数值永不成长。已有特殊形态／继承方向继续保存，初期不据旧保留意见自动加入本体配置。

普通技能在初期自动执行。G02-C01／C02 将来取得施法权或操控权的候选不要求现在设计手动技能栏或宏；也不能用它们否定自动技能结构。

### 依赖与恢复

关联 I15：M01 已定初期固定能力边界，M04／M05／M06 在该边界下处理外部效果联动，R02 处理培养，R07／R08 处理不含随机个体词条的英雄供给。扩展能力栏、替换整个技能包、特殊形态／继承等后续材料不在初期展开。

I01 的旧字段属于技术核对；I14 的随机候选开局是已确认目标待整合。二者不作为本轮重新决定主英雄身份的前提，也没有授权修改运行代码。用户继续后已核对基础动作与自动施放基线，阶段交接如下。

### M01 阶段收束与交接核对

2026-09-06：以下为 Agent 对现行基线与议题归属的核对，不是新增用户决定，也不是能力系统已经实现或验收。

- M01-D01 已确定初期固定主动＋固定被动、本体不配置及无随机个体属性。其余能力构成候选保留后续，无需继续选择多技能栏。
- [现行核心规则](../../../gameplay-design/tower-autobattler-core.md)已有攻击／治疗基础动作、每名英雄独立的战斗内法力、满蓝自动尝试施放；受控、恢复阶段或没有合法目标时保留法力。法力来源已有时间恢复、每次基础动作（含治疗动作）及实际受伤／护盾吸收的 authored 上限，成功施放清空法力并进入恢复。没有从用户最新决定中发现必须重新选择整套资源制度的冲突，不凭“还有这个栏目”创造表决项。
- 合法目标、可达路径、距离含义与目标稳定转 M02；状态及效果关系归 M04，装备／遗物影响归 M05／M06，培养数值归 R02，随机候选供给归 R07／R08。已有基线在这些问题出现真实差异时再核对，不先改写权威。
- I01 仍待技术核对；I15 固定主动／被动目标与权威及外部联动待统一整合。它们不要求现在实现或阻塞后续讨论。
