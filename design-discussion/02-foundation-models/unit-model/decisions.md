# M01 单位／英雄模型：讨论决定

本文件仅记录讨论结果，不是现行玩法或实现权威。进程见 [总览](../../roadmap.md)，原作比较见 [H01–H12／HL01](evidence.md)。

## M01-D01：初期固定主动与被动，不做本体配置和随机个体属性

日期：2026-09-06。状态：**已确认但未合并**。适用范围：M01-Q01 的初期英雄能力模型。用户选择 H03 的固定主动＋固定被动，并收窄 Agent 原 P01 的扩展建议。

### 当前结论

- **英雄采用固定的一项主动技能＋一项被动能力。** 能力内容由英雄定义；主动在初期按 G02-D01 自动执行，不因称作主动就增加手动操作。
- **英雄本身在局内不提供可配置内容。** 初期不提供本体技能自由装配、更换、可选天赋／特性教学等配置层；也不把纯被动、多技能或武器替换整套动作当作初期常规变体。原 P01 建议的可变能力数量与 H09 本体扩展没有被采用。
- **暂不做随机个体属性／特性。** 同一英雄不因本局招募而额外随机基础属性、天赋或个体词条。同样的英雄与成长条件使用一致的基础定义，避免玩家还要寻找满足体系要求的随机个体。
- **其他思路保留后续参考，初期不展开。** H01–H12／HL01 的证据与细节原样保留，不据此安排初期功能。历史保留的特殊形态、进化、继承等方向不自动进入初期，也不视为永久撤销；以后扩充时再按明确范围讨论。

### 与已有决定的关系

- G03-D02 的随机候选开局与随机招募继续成立：随机的是提供哪些英雄，初期不再为每个英雄叠一层随机个体定义。阵容适配推荐及其他体系选择空间不变。
- 已确认的装备／遗物配置、效果联动、培养成长和换人仍按各自边界继续；“固定技能”不等于英雄数值无法成长或装备不能影响技能效果。它也不授权装备替换整个原生技能包或新增一套本体技能栏。
- 本次采用 H03 的能力构成，不采用 Astronarch 的两次升级、资源数量或培养公式。技能具体效果、成长数值及开放时点未由本次确定；不能借未定参数自动添加 H04 的分阶段新增能力体系。
- 普通攻击／治疗等基础动作不被主动＋被动的表述取消。法力来源、施法节奏和合法性继续以现行规则为讨论基线，需在后续真实子问题中核对，当前没有改写。

### 理由与后续归属

用户认为其他思路有道理，但不适合初期；随机个体属性还会显著干扰玩家组成体系。因此初期保留稳定、可辨认的英雄内容，把局内差异放在已有的阵容、培养、装备／遗物与配合中。

M01 承接固定能力与自动行动边界；M04／M05／M06 承接属性、效果和外部内容联动；R02 承接既有培养方向；R07／R08 承接固定个体定义下的随机供给。关联 I15。当前实现首批一个满蓝技能的基线不能直接当作固定主动＋被动目标已完成，统一整合时再核对权威及实现，不在讨论轮写代码。
