这是与玩法讨论并行的表现系统专题，不改变主线玩法议题的恢复点，也不代表批准 M04 公共效果规则。

- 边界：高质量特效的资源、播放、生命周期、战斗接入和独立前台预览；不重做伤害、子弹碰撞或技能规则。
- 用户要求、现状与建议分别见 [decisions.md](decisions.md)、[evidence.md](evidence.md)、[proposals.md](proposals.md)。
- D41补充牧师法杖在受击者身上降下光柱，S74记录具体演示／未知项／分层适配；正式命中路径、原速对照与局部实际输入见远程攻击活动任务。伤害规则保留，新观感待用户。
- D41后续用户接受落柱方向但指出材质丑；S74续记暖白光芯／淡金外晕、接触面与碎光局部修订，默认结果页已有材质原速对照。新材质待用户，不扩大认可范围。
- D40认可天气样板并讨论与进程融合的软叙事；来源和现状见S75，可组合候选与单向展示依赖见A05。具体世界观／制作范围待讨论，不扩大为运行时实施授权。
- D39要求远程普攻按单位区分表现并保留伤害规则；《元气骑士》官方动作观察与项目适配见S73，绑定、动态录制及实际验证见[远程攻击活动任务](../../../work-items/active/ranged-attacks-and-basic-effects.md)。新效果待用户评价。
- 战斗场地的展示层研究也归此专题：现状与参考见P01-S59–S60，首版接入见S61，上一版实时光影见S62。D29要求云影、D30要求可见动态与联动后，D31指出光束像撕裂痕迹，要求画面外照入的平行日光；当前形状、遮光关系、正式Run原速录制及独立空气层检查见S65。S63–S64保留首轮参数与被否定形状的历史，蒙版定位修复仍有效。改进项ENV01–ENV10及制作路线见A04；D27–D31授权当前样板，执行／验证归活动任务，新动态观感待用户评价。
- D38新增独立雨／雪／雷雨背景，仅属展示层；天气预设、共享场景、实际输入与正常速度录制见S72，预览入口为“练习与预览 → 天气预览”，新观感待用户评价。
- D37要求降低向阳地面的亮度并让光束中心亮、向外多层减弱；共享三层柔光轮廓、平滑透明度及HUD隔离验证见S71。
- D36要求修正云影与光束空间配合：共享二维地面受光区、从足迹重建空气、正式及无遮挡共用资源原速记录见S70，新的联动观感待用户评价。

- D34移除固定树冠投影，云影细化为四尺度、同向差速的柔软云团；源码绑定移除、正式原速录制与验证边界见S68，观感待用户评价。
- D33要求顶部入光、部分落地：三处不同深度的宽柔收尾、地面受光斑及正式原速验证见S67。D32的大小云团差速与透光区移动继续沿用，动态记录见S66；S65弱动态保留为历史。
