# M05 装备模型

进程状态与当前讨论点见 [总览](../../roadmap.md)，不在此重复维护。

## 决策边界

- 要决定：装备归属、槽位限制、效果接入、重复/互斥及成长接口。
- 不涉及：不列装备和词条数值，不加入背包拼图；当前免费转移规则保持。
- 前置或协作依赖：M01、M04
- 本议题期望产出：装备的能力范围、约束和与英雄的组合接口。

## 阅读与记录

先读 [讨论区约定](../../README.md) 和 [跨议题问题](../../05-integration/cross-topic-issues.md)，再读取与本题相关的现行权威。现行规则是本轮基线，修改建议只记录在讨论区。

- [已有证据](evidence.md)：Q01 同名重复穿戴与限制范围，E01–E06；直接原作证据、现行路径与项目对照分开记录。
- [方案讨论](proposals.md)：保留普通重复穿戴基线，必要限制归明确内容的建议；不重选三槽或免费转移。
- [用户决定](decisions.md)：D01 装备允许重复穿戴，叠加与唯一由词条控制；D02 词条与数值固定，可以升级品质。遵循 [记录约定](../../topic-records.md)，不把示例扩展成所有特效唯一或把品质成长推定为某种升级配方。
- Q02 见 [E07–E11](evidence.md) 与 [Q02-P01](proposals.md)：同种装备获取时的固定定义、随机数值、随机词条、固定核心加随机附加，以及可组合的品质维度；取得后的强化／镶嵌等另行归属。
- Q03 见 [E12–E19](evidence.md) 与 [Q03-P01](proposals.md)：品质升级的投入来源、重复件穿戴机会成本及失败风险；品质具体增强内容另行讨论。
- [D03](decisions.md)：材料尽量通用，升级提供可选成长收益；与金币分开、高级 Boss 稳定产出特定材料保留可考虑方向，不把升级变成推进硬门槛。
