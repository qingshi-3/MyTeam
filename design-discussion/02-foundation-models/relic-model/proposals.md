### Q01-P01：初期保留获得后累积的普通遗物路径，不新增启用槽位

Agent 建议初期沿用 L01：新获得遗物直接加入本局规则集合，按其自身条件生效；不新增普通遗物总槽位、启用预算或每战选择一套遗物的管理层。

这保留从早期探索逐步形成组合的连续性，装备已经提供三槽与持有者分配，遗物可主要承担本局规则的累积变化。代价是后期效果数量增长、组合强度与说明负担，需要通过获取机会、明确内容与供给控制，而非假定无槽位天然平衡。

L02 可用总数限制制造更强替换取舍，L03 可给每战适配，但会改变初期遗物体验并新增库存启用行为；L04–L06 提供预算／分类／阶段方案，暂不建议为管理效果差异而全部建立。L07 特殊承诺保留参考，没有采用强制获得或禁止移除。

无普通容量限制不等于无条件触发、同名无限堆叠或普通遗物永远不可移除。本题不替用户决定主动丢弃／卖出／转换权限，不把获得后的常驻规则与事件已发放的永久收益混成一件事；这些后续生命周期核对仍需要保留。

## M06-Q02：已获得遗物的主动移除权限

状态：已收束，用户结论见 [M06-D02](decisions.md)。以下保留原提案及当时的待定表述。完整 L08–L12 及证据边界见 [已有证据](evidence.md)。本题不重新讨论槽位，也不讨论同名叠加算法；无容量压力时，移除的主要意义是解除旧规则与支持转型。

### Q02-P01：常规获得后保留，移除或交换由明确的特殊机会提供

Agent 建议初期采用 L08 的常规方向：不新增随时免费丢弃或普通出售按钮，让获得遗物保留本局承诺。若具体内容需要退出或转换，可通过 L11／L12 式明确机会提供，是否初期制作及其资格／费用另定，不要求建立全套服务。

理由是普通遗物无容量上限，不存在必须腾槽的需求；随时清掉持续代价或把暂时无用遗物变现，会改变获取时的取舍，也新增一套经济。代价是遗物之间若发生体系冲突，可能压缩 G03 的转型空间，因此有代价／强约束的获取需要清楚预告，并与可选性及后续出口相匹配。不能据本建议直接强制发坏遗物，再靠稀有移除服务补救。

若用户更重视随时摆脱旧规则，L09 无返还丢弃比 L10 出售更少增加经济层，但仍需明确一次性收益与持续代价的关系。这里保留真实取舍，没有替用户确认常规不可移除，也不把现行缺少移除操作当作产品已定。

I22 与 R08／R09／R12 衔接取得、退出机会及资源结果；具体遗物到期、消耗或特殊启用继续归内容。用户可明确常规权限及特例方向，不必逐项审批全部形式。本轮未新增决定，未改权威、实现或研究原库。

Agent 建议以 L13 为普通供给默认，并采用 L15 的内容自由度：普通遗物获得后不再进入普通候选，确有重复投入价值的遗物可明确允许再取。这样通常通过新遗物扩展组合，少量内容仍可强化已有方向；不硬性按“数值／特殊”划类别，也不把某条唯一效果扩大为整件所有收益失效。
