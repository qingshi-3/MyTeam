# M06 遗物模型

进程状态与当前讨论点见 [总览](../../roadmap.md)，不在此重复维护。

## 决策边界

- 要决定：遗物作用范围、获得/移除生命周期、叠加互斥和可改写的基础规则。
- 不涉及：不列具名遗物；蒸馏/融合/进化仅作特殊规则边界样例，不建设普遍养成。
- 前置或协作依赖：M01、M03、M04、M05
- 本议题期望产出：遗物与普通内容的区别、规则改写护栏。
