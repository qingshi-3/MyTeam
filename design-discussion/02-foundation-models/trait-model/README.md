## 决策边界

- 要决定：羁绊如何赋予、贡献和计数，如何激活档位、选择受益者、动态更新与撤销。
- 不涉及：不列具体羁绊或档位效果；现有计算政策先核对，不默认推翻。
- 前置或协作依赖：M01、M02
- 本议题期望产出：贡献—激活—受益—失效模型与必要例外。
