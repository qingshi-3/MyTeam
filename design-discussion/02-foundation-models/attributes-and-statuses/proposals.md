# M04 属性、状态与效果关系：方案讨论

## M04-Q01：同一种状态反复施加时，新增投入怎样保留和生效

状态：按 [M04-D01](decisions.md)收束，已确认未合并。完整原作过程、模型例子与证据限制见 [W01–W12](evidence.md)；下文保留原建议，不将用户对内容分工的确认扩大为逐条采用。

### 已定边界与本题目的

跨英雄供给／兑现及装备通过通用状态联动已经是已确认方向；M01 固定主动＋被动、M03 贡献／受益分离、G02 初期纯自动均不改变。现行状态模型有多种叠加和持续政策，本题不要求把它们逐项重新批准，也不要求选择一种供全部状态使用。

本题要明确跨内容是否遵守可辨认的同类状态规则，以及如何描述重复施加的实际价值。W01–W12 是不同维度的材料，可以组合，具体状态选择哪种归内容设计。举例数字均不是新内容或参数方案。

### M04-Q01-P01：不同状态采用合适的叠加方式，同一共享状态保持一致语义

Agent 建议：

- **不同状态各有合适的积累方式。** 可以增加强度、提高覆盖、积累时长、独立到期或到门槛产生新作用；不能因为某状态叠层，就让所有状态、护盾和控制跟着使用同一算法。W01–W12 保留完整素材，不安排首批逐项覆盖。
- **同一种共享状态跨英雄、装备、羁绊、遗物保持可辨认的基础含义。** 玩家知道甲施加的某状态与乙施加的同名状态，是否可合并、怎样失效、是否给同一读者使用。特定载体若改变上限、消耗或刷新，必须是明确内容效果，不让玩家从来源名字猜隐藏差别。不同来源可以提供不同量；同名并不要求数值相同。
- **把新增投入的实际价值说清。** “再加一层”“续时”“保留较强者”“独立一份”“达到门槛”分别描述。层数上限和持续上限不是一个东西，刷新状态也不应在文案上等于立刻结算一次。满层是否续时、消耗后剩什么，由该状态和显式读者决定。

这里不额外建议一种所有状态共用的默认算法，也不因 W07 的原作例子提前决定项目护盾只能留最强，更不以 W06 为由默认容许无限长控制。

### 构筑后果与代价

玩家招募第二个供给者时，应能知道是在提高伤害、缩短满层时间、覆盖更多目标、维持不断档，还是与现有强效果竞争。这比只写“同类效果可叠加”更能解释取舍，也让功能英雄与装备能用同一套状态语言联动。

代价是需要分别描述状态的层数和时长规则。应优先清楚表达具体首批内容所需的规则，而不是为了模型齐全先引入全部案例。W03–W06、W12 缺少直接原作精确证据的事实保留；现行代码存在相应政策，不等于其内容和平衡已验收。

## M04-Q02：是否给连续硬控增加全员通用的脱控保障

状态：已按 [M04-D02](decisions.md)确认未合并，Q02 收束。完整比较与证据范围见 [CC01–CC08](evidence.md)，下文保留原推荐及取舍；M04-D01 不变。

### 基线核对与范围

读取属性／状态、共同效果、来源与反应契约后，已有读取／转换与队列边界可以继续作为基线，具体读者／消耗／净化内容不重选。现行静态控制抗性缩短时长，不等于全员累积抗性或必定获得行动机会。连续控制可能压住某个局部战线，影响 G01 的牵制、突破与自动转战；初期 G02 无手动操作，不能由玩家临场解控弥补。这使防永控的适用范围成为尚未明确的公共问题。

本题不为所有控制设同一时长／叠加方式，不决定每种控制可驱散性、Boss 名单、净化技能、免疫时长、抗性曲线或掉落概率。研究中劝阻永控的 transferability 等字段是研究者建议，不是用户已经采纳的规则。

### M04-Q02-P01：初期不额外给全员加自动脱控保障，控制链与反制通过明确内容成立

Agent 建议：

- **初期不默认加入全员受控后递增抗性、脱控后固定免控或必定完成一次行动的保障。** 不推翻现行可配置的控制抗性；“没有额外通用保障”与“所有目标零抗性、全程可控”不同。
- **允许投入成型的控制阵容在合适对局形成连续压制。** 能否成立仍受供给频率、资源、范围、目标接近、多个威胁与控制者生存影响；不保证一套控制能压住全部敌人，也不要求每局一定发生永久封锁。
- **关键目标的反制可归明确内容。** 时长抗性、阶段免控、施法保护或特定类别免疫可用不同方式设计，不把全部 Boss 一律做成完全免控，也不因本提案采用某个具名机制或首批配额。CC03 累积抗性仍保留特殊机制候选，不自动成为所有单位共有规则。
- **敌方控制同样遵循公开的效果规则。** 其控制链强度、可预告性、攻击者能否被处理、准备阶段能否取得有效应对，需要与 R12／供给／遭遇设计衔接。CC07 自动净化可以成为内容答案，但不是每场强制携带，也不引入临场手动解控或隐藏玩家侧豁免。

### 推荐理由与代价

依据已定构筑体验，控制可以成为生存投入和成型后的兑现方式；若所有目标都自动随受控获得保护，会预先压低高频多控制的收益，也会引入所有单位需要理解的附加状态。将反制写进可识别内容，可以保留不同对局的强弱差异。

代价是平衡与遭遇设计负担更大：廉价控制若可轻易覆盖整场，控制可能替代过多其他生存手段；敌方若形成难以预告或无法应对的封锁，玩家可能看着核心始终不能行动。不能只靠“以后给一个免控 Boss”掩盖控制在大量普通遭遇中的失衡，也不能让反制依赖唯一稀有掉落。上述是方案代价，未声称已有数值／供给完成或实测通过。

若用户更重视“任何普通单位都不能长期失去行动”的体验，则须改变公共边界，再比较 CC03／CC08 的适用范围；CC05 只保护已开始的施法，不能独自兑现该目标。当前没有替用户采用这个方向，也没有因研究案例要求必须二选一某个具体算法。
