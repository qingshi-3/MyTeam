# Work Items

`active/` contains confirmed, self-contained work that still needs discussion resolution, execution, or independent verification. It records task scope, progress, evidence, and resume state without overriding accepted gameplay or system authority.

`archive/` contains completed historical work items. Only tasks whose acceptance criteria have passed independent verification and whose status is `Completed` move there; `Needs Discussion`, `In Progress`, and `Awaiting Verification` tasks remain active.
