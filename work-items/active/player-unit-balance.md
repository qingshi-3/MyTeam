# 玩家单位数值、治疗与怒劲校准

## 当前追加：阵容交战诊断（2026-09-26）

用户授权用当前内容分析搭配、制定预期并执行模拟战，按全局分工由 Astra 制定实验与审查，gpt-5.6-sol 执行采集和统计。本轮冻结正式数值、技能和遭遇配置；允许增加可复用诊断入口与数据文件，不自动根据胜负调参。此前首轮校准结论保留，不能替代此次当前版本的实测。

实验规格与结果归 `design-discussion/04-content-validation/artifacts/player-balance/matchup-diagnostics/`。复用实验室和征程共同的准备／模拟核心；真实阶段敌人由正式遭遇准备路径提供，不能拿实验室默认原始倍率替代后期难度。所有战斗均从隔离内存状态开始，不触碰玩家存档。

预先登记的诊断问题：

1. 通用前排＋治疗＋远程是否能过渡，但在第9／14层及阶段Boss逐渐吃力；记录实际存在的羁绊，不能把有配合的组合强称零协同。
2. 棘毒、召唤、霜羽成型阵容是否各有可兑现窗口；在相同人数和装备／遗物预算下，替换一个关键配套后是否出现可解释损失。成员、装备、遗物的变化分别列出，预算不足或品阶不同须标注。
3. 普攻／暴击、护盾、怒拳等现有搭配能否兑现职责；正式征程17人池与实验室扩展英雄分组呈现，不能混为自然可取得的路线。
4. 输出、有效治疗／溢出、实际生命承伤／护盾吸收、控制次数／目标实际受控时间、首个技能／次数、存活／死亡、召唤物贡献必须尽量按单位输出。缺失指标明确为不可得，不用估算冒充精确归因；控制重叠不能重复累计为队伍受控时间。

采样约定：固定种子1776、2026、9173、4109、8128；同组使用相同敌阵、站位及种子。第1层用于起步参考，第4／9／14层普通和精英、第5／10／15层Boss用于阶段压力；允许只在适合该进度的阶段加入高阶核心。每个组合先5个种子，只有异常或关键结论需要时扩样。保存完整单位清单、装备持有者、遗物、羁绊、位置、实际敌方倍率／属性、源码或内容指纹和结果摘要；保留超时与失败，禁止筛掉不利样本。

以下是 Astra 预设的筛查阈值，不是新玩法权威或统计上已证实的胜率：起步常规职责组合目标至少4/5胜；首区过渡组合目标至少3/5；末区无专用配套组合目标至多1/5；成型队末区普通／精英目标至少3/5，终局Boss至少2/5。中区观察通用队相对成型队的余量下降，不要求所有散搭必输。完整配套对缺件对照，在两个以上压力场景中应至少出现一项稳定优势：多胜至少1/5，或同胜样本中位耗时减少20%，或前排存活中位时间增加20%；同时查看其他指标，不能拿单一指标补偿严重整体倒退。5种子只作筛查，不报为自然胜率；不同种子若敌阵同时变化，明确为混合场景而非纯随机重复。

判断层次：先核对采集和配置正确性，再判断数值／机制／站位／阵容条件问题；最终只报告证据支持的异常及建议，不强行让每套阵容同强，不把缺件必须全败当目标。执行 Agent 独占新增诊断代码及原始产物；主 Agent 维护本任务、实验预期和最终结论。构建与Godot运行串行，避免与其他工作共享生成产物冲突。

状态：诊断完成。10套阵容、18名英雄、320个有效主矩阵样本，追加40个末区入口／站位样本；[主责结论](../../design-discussion/04-content-validation/artifacts/player-balance/matchup-diagnostics/report.md)与[有效汇总](../../design-discussion/04-content-validation/artifacts/player-balance/matchup-diagnostics/summary-final.md)已保存。首次夹具有30场近战重复格漏人，已保留无效证据、修复并仅重跑受影响部分；有效数据做身份集合检查，未把原护盾0胜错误结论沿用。构建与独立事件／报告校验、来源指纹检查通过，原始／修正／追测各1次digest复跑一致。正式数值与存档未改。

核心结论：通用队前期均可过渡、末区全败；完整体系已有质变收益。第11层四组均5/5，未发现第二Boss后立即断崖。第14精英对棘毒压力仍高（两种站位0/5、1/5）；霜羽换站位从1/5→3/5，终Boss3/5→5/5，不支持简单全面补强。召唤默认末区精英4/5、终Boss5/5，临时单位输出与承伤预算需重点审查。护盾完整夹具终Boss4/5；暴击／双治疗怒拳配方仍不足，不能推广为整个玩法不存在。下一步按报告优先级局部诊断／调参，不重复跑整套，不将建议当已实施。

- 普通攻击不因治疗强度而替换为治疗，HC18／HC19保留各自技能治疗和被动；技能仍正常回蓝、寻路、选取受伤对象。
- 正式HC38怒劲战内持续，实际生命承伤积累、上限、消耗、死亡清理及原三类触发保持；等待目标／控制期间保留，战后重建，不恢复跨战积累。
- 逐名核对基础生存、基础输出、技能频率、恢复与机制收益；保留角色差异和必要体系发动能力。
- 用正式准备／模拟采样所有发布英雄及现有阶段构筑；数据是固定条件对照，不代表自然获取率或最终玩家胜率。
- 检查敌方资源依赖与指纹，玩家调参不修改敌方基础数值／技能；共用贴图、动画、VFX和行为组件。只有需要独立调参的资源才拆分。
- 低并发构建；重点验证普攻／技能治疗、长时间／间歇承伤蓄怒、队列及回滚、敌我资源隔离。用户负责手动强度与节奏验收，不重复录制VFX。
