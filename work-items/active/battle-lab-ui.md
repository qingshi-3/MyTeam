# 战斗实验室 UI 与交互优化

## 碰撞／普攻可视化与 EE03 体型校准（2026-09-21，已实现）

用户要求看见真实碰撞和攻击范围，并指出冲锋单位素材小、占位大，会造成看似能过的通道无法通过。本次执行沿用现有 main，无提交或玩家数据操作。

- 战斗上方新增默认关闭的「碰撞」「普攻范围」开关。实线显示存活身体，黄色虚线显示选中单位的身体半径＋动态普攻射程；当前目标两身体最近点连线显示实际边缘间距与射程，地形不通另作标记。碰撞层也显示完整阻挡格、空中虚线投影和带叉预留落点；技能独立范围不冒充普攻范围。
- 独立 authored `BattleGeometryOverlay` 消费 `BattleSimulation.ReadSpatialSnapshot()` 不可变值，读取现有射程／通路规则，不复制战斗逻辑或修改模拟。开关开启时呈现位置按实际战斗步对齐，避免动画插值滞后让碰撞圈偏离角色；关闭恢复普通呈现路径。点选只切换观察对象，单位详情按钮仍可打开面板；暂停、单步、投影改变、重置和退出同步清理／更新。
- EE03 f5_tank 待机帧可见宽度61–62像素，VisualScale 2.1，对应88像素格距下约1.46–1.48格；旧身体直径1.8格过大。本次半径0.9→0.7，直径1.4，保留大型定位和已有美术比例。部署、寻路、冲锋与普攻边距均读取同一体型。移除战斗单位缩放单独钳在0.9–1.4的限制，角色和棋盘投影同步缩放，不随窗口增大出现碰撞比素材越大。

验证：低并发.NET构建0警告／0错误；`BattleGeometrySmoke`无窗口检查实际普攻0.24／0.25格可打、0.27格不可打、射程内地形阻挡、动态体型不可变投影、读快照不改变确定性结果、不同投影尺寸的比例。净宽1.56格的身体通道中，校准后直径1.4的巨兽走过并普攻，旧1.8对照被挡，均不穿透。`--input`使用正式BattleScreen隔离实例，真实鼠标开关／暂停／选单位／单步、键盘开关、接敌伤害、退出／重新开战通过；已查看分离与接敌截图。原`EnemyTrampleContractSmoke`通过，墙边夹具按新半径收窄后仍验证无法分边就停止；法力、锁向、多目标、友军安全和回滚保留。日志 `.godot/ui-review/geometry-contract.log`、`geometry-input.log`、`geometry-trample.log`，截图 `geometry-separated.png`／`geometry-contact.png`。未重跑整局或进行全分辨率截图扫查；用户负责拥挤感、体型观感与冲锋平衡验收。

补充图形验证：正式EE03技能开启诊断后仍进入冲锋移动阶段，真实点击暂停时身体圈与单位位置一致，退出同时清空冲锋表现和范围。已查看 `.godot/ui-review/geometry-charge.png`；最终 `geometry-input.log` 通过。首次补充夹具的400渲染帧等待在高刷新率下早于蓄力完成，延长有界观察窗口后通过；未改技能或模拟时间。

## 优化方案

主要配置流程固定为“选择单位 → 布置棋盘 → 查看／配置选中单位 → 检查就绪 → 开战”。全队配置和实验参数保留独立入口，避免随选中单位混入同一长面板。

| 区域 | 调整与作用 |
| --- | --- |
| 左侧单位库 | 我方／敌方分标签；选单位或拖入棋盘，搜索与列表在本区内滚动。 |
| 中央棋盘 | 保持 10 × 6，格内显示独立头像、名称和阵营；正式模式用边框与提示标记部署区域，自由模式不显示区域限制。清空操作靠近棋盘，只清空单位、保留遗物，并提供 32 步内存撤销。 |
| 右侧检查区 | 分“单位／团队／设置”：单位页按既有 Session 资格提供装备编辑，目前允许我方单位（包括假人），敌方不适用；团队页放遗物与队伍信息；设置页放规则、种子等实验参数。 |
| 预设浮层 | 搜索、可见候选列表、摘要、加载与保存集中在独立浮层，区分内置与我的预设，支持双击／键盘加载及 Tab 焦点循环。保留全部 31 个既有预设；标题显示当前配置名，反馈留在浮层内。 |
| 固定底栏 | 就绪状态、失败原因与开战按钮始终可见；只在各内容区内部滚动，取消整屏滚动。 |
| 按需细节 | 内容 ID、来源追踪等技术信息折叠展示，常用面板优先呈现中文名称、装备和战斗属性。 |

交互明确区分单击选择与拖放：位移达到 8 像素才进入拖动，点选与键盘共用按钮激活路径；支持连续点放、选中棋盘单位后点击空格移动。Esc 取消当前操作，Delete 删除已选单位，但输入框内编辑文字时不触发删除。32 步撤销覆盖成功的会话编辑与预设加载。切换遗物或团队页不丢掉当前单位选择。种子应用、保存与开战读取一致值；保存拒绝与内置预设重名。派生配置按会话摘要缓存，单位能力快照同样缓存，避免无变化时重复准备。

单位常用属性加入防御；技能介绍保留主动与被动，包括 HC01 通过 `AttackHitGrowth` 组件提供的叠速被动和当前换目标保层覆盖，不把这部分藏入技术详情。头像复用独立 `UnitPortrait`；共享 RealmTheme 增加实验室标签、列表项、预设列表、折叠与棋盘格专用变体，沿用共享语义颜色，没有新增美术。

这些是本轮界面实施选择，未修改内容效果、布阵合法性、实际战斗或生产存档规则；最终数值与战斗体验仍归原内容任务。

## 当前扩展与交接

### 技能短句与词条

用户指出追刃客悬停说明像小作文，要求通过两字词条、语义颜色和加粗区分重点，并以词条组合表达复杂技能。本次调整属于说明呈现，不改变战斗效果或数值：

- 提示卡顺序调整为身份 → 主动／被动 → 次要属性／配置 → 简短操作提示。主被动标题加粗，词条按输出金色、控制紫色、防护蓝色、恢复绿色区分，数字单独加粗。中文粗体使用共享 Theme 中的 700 字重字体。
- `CombatRichText` 接收纯文本，由安全转义后的渲染器生成富文本；词条名称、解释与颜色来自 authored `content/ui/combat_keywords.tres`，不进入战斗执行。实验室提示、单位配置、装备／遗物完整效果、战斗点选详情共用这套呈现。颜色之外仍有文字名称和字重线索。
- 同一主动／被动类别内按显示名称合并技能块，保留各组件效果并去掉完全相同的说明。追刃客的“猎刃本能”只出现一次；不是合并运行能力、触发器或冷却。
- HC01、HC03、HC04 补充／精简 authored 描述。追刃客写成“常驻：暴击 +15%”和“普攻暴击：追击（触发间隔 0.2 秒）”；“追击”解释清零攻击等待、下一次仍需完整普攻动作。连弩手保留 3 箭、65% 攻击力及随当前攻速变化的 50% 间隔；成长不错误限定为仅普攻命中。铁甲卫保留 2.5 格／3 秒嘲讽、防御 +18／3 秒和基于当前防御的普攻反伤。
- 悬停不展开全部词条解释，也不截获棋盘输入。点选单位在右侧查看所用词条释义；点选单位库原型也明确展开单位页。战斗技能点击后在“效果说明”固定全文与释义。装备和遗物仍保留读取实际编译效果的完整规则，不用词条覆盖目标资格或层数规则。
- 当前为共享词条呈现与三名英雄短句整理，未声称所有内容均已逐条改写。后续可沿已有词条资源扩充；不同结算规则不能为了缩句而混用一个词条。运行、输入与可见观感均未验收，沿用用户“不用验证”要求。

本轮以下扩展已完成实现与接入；这里不表示运行或用户体验已经通过：

- 单位、棋盘实例、技能、装备与遗物提供按需悬停说明；鼠标查看与键盘焦点共享可读内容。装备与遗物读取发布后的实际效果、供给对象、触发条件和层数关系，不仅显示 `ItemDefinition.Description`。
- 实验室左侧单位库与右侧配置区可以分别折叠，保留搜索、选择及当前配置页；展开入口持续可见，中央棋盘获得释放出的空间。
- 战斗侧栏可以收起和展开，集中选中单位与战斗统计；战况条读取当前战斗已经结算的真实数据，解释口径与单位归属，不用示意数字或仅由生命条推断输出。
- 详情与统计只投影现有运行状态，不改变伤害、治疗、施法、目标选择或存档规则；实测可用性和观感仍由用户后续体验。

主 Agent 负责实验室场景、布局、共享 Theme、只读统计接口与最终整合；子 Agent 分别完成悬停内容／组件和战斗表现侧栏，独立 Agent 梳理真实物品效果接口。所有文件归属已交还并完成接线。全部工作在同一个 main 工作区，不构建、不运行测试、不启动 Godot、不试玩或录制。

- 实验室默认左侧单位库展开、右侧配置收起。两侧常驻窄工具栏，F1／F2 或箭头独立切换；右栏的单位／团队／设置按钮直接打开对应页，再次点击当前页可收起。点击棋盘单位展开单位配置；收起保留选择、搜索和当前页，并归还可见焦点。棋盘按释放后的容器空间调整格尺寸。
- `BattleLabTooltipInfo / Formatter / HoverHint / Tooltip` 提供 authored 提示场景和只读格式化。单位库和棋盘单位分别绑定基础／当前配置事实；0.22 秒 hover 与键盘焦点共用提示，拖拽、折叠、预设浮层、隐藏和退出清理。按视口与字体行高提供摘要，主被动分别保留空间；不截断完整 PlainText。右侧新增“装备完整效果”和“遗物完整效果”，可展开阅读候选及已配置物品的完整规则。
- `BattleInspectorDock` 默认折叠，保留战况／单位入口与选中单位摘要。点击战场单位展开详情，常规 tick 不改变展开状态；收起按钮和栏内 Esc 回到侧轨焦点。属性、主被动、装备和状态支持 hover，点击可将全文固定到“效果说明”。
- `BattleSimulation.ReadUnitReports()` 仅返回当前或终局不可变报告投影，不结算战斗、不生成 digest；只在统计页可见时读取。战况支持双方伤害／承伤／有效治疗，按开场阵营归属、包含召唤物；伤害与承伤包括护盾吸收但不包括过量伤害，治疗不包括过疗。条长相对本侧最高值，点击统计行选中实际单位。此前位移动作／特效、暂停、倍速、单步与清理接线保留。

已定位可复用接口：`BattleLabContentIndex.Package.Content.Graph.ResolveEquipment / ResolveRelic` 提供编译后的真实规则；`EffectModelText` 提供属性名称、数值表达式、条件与效果对象说明；`StatusModelText` 提供持续时间、层数、周期及事件触发说明。遗物层数来自实验室实例配置，与状态层数上限分别表达。现有遗物目标过滤中，`PlayerArmy` 实际指我方初始、非临时、非英雄单位；英雄目标仅初始非临时英雄；邻接目标读取存活友军的实际身体边缘距离。悬停文案应如实对应这些执行条件，本轮不暗改其行为。
