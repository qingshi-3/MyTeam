# 贯穿特色兵首批落地

## 授权与范围

2026-09-16 用户在 D40 / D41 双形态与资源分离确认后要求“做呀”，授权实际实现 ES01 贯阵弩手与 ES04 贯光术士。保留已有 main 工作区改动，不提交、不操作玩家存档。

- 物理飞行贯穿箭与魔法瞬时贯穿光束，技能独立于普攻射程。
- 方向预警 → 充能渐亮 → 释放 → 命中与收尾；蓄力开始锁方向，控制、死亡、强制位移取消未释放技能。
- 单位场景、技能定义/挂载及 VFX 资源分别维护；战斗可变状态只归实例。
- 初值：1.2 秒蓄力，最多 2 个目标，第二目标衰减；数值为待试玩调参值。
- 接入内容目录、隔离战斗预设和有限正式遭遇；不扩展 ES02/ES03 或整套英雄重设计。

## 试玩与恢复入口

主菜单 → 战斗实验室 → 内置预设，搜索 **ES01** 或 **ES04**，载入“预警与贯穿”后开战。观察方向预告是否够清楚、源端渐亮到释放是否连贯，再改变前后排的共线／错位站位，对比同时中招人数；可加控制单位检查蓄力打断。实际玩家反馈优先调整时序、宽度和压力，不把自动检查当作认可。

复查仅按相关变化运行上述检查；渲染入口支持 `--fixed-fps 60 -- --capture=<目录>`。不需要重复导入、全量回归或接触玩家存档。
