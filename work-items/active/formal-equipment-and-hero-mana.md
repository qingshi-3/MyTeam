## 实现契约

- BattleSimulation 保持唯一战斗权威；能力仍使用既有 authored loadout、编译图、操作和事务，不写具体英雄 id 分支。
- 英雄当前法力是独立 Battle 状态，不写共享 Resource，也不跨战保存；上限、起始值、三种回复可配置。法力达到施法门槛但没有合法目标或受到行动控制时不消费；成功施法才消费，失败回滚。
- 攻击回蓝以一次普通攻击为基准，不因溅射/穿透重复；受击回蓝只计算有效承伤，不从无效伤害或尸体产生；被动回蓝按逻辑 tick，不受渲染帧率影响。
- 法力条、技能及状态表现读取真实 runtime 快照与事件，不伪造触发；角色有清晰装备槽与效果详情，技术 id 退出常规展示。
- 正式装备获得、归属和更换复用 Run 的原子命令及持久化；替换不得默默销毁旧装备。资源变更限于明确接入的装备/英雄技能内容。
