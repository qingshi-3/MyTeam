# 招募基础落地：受控池、6选2、阶段分阶

日期：2026-09-16。状态：已实现；编译、专项契约与实际输入检查通过；整局节奏与平衡待玩家体验。

## 目标、授权与边界

用户在明确上述缺口后要求“执行落地呢？还需要我补充什么才能执行吗”，授权将已讨论的基础流程落入游戏。这是 R07-D03/D05 与内容 Q11/Q12 的局部提前实施，不扩大为整个讨论区合并。

- 正式征程采用14名受控测试候选；目录中其他英雄仍可用于实验室和已有存档。
- 开局保存6名互异候选，选择/取消并保存，恰好2人确认后进入首战备战；不附送第三人。
- 当前测试池按4阶组织，一二阶开局。此名单与权重是 Agent 采用的首版可调参数，不声称用户逐项认可或已平衡。
- 阶级抽取先于阶内英雄抽取。已持有（含后备）、批内重复被排除；空阶只向本阶段允许的非空阶重分；不足则少给，耗尽可跳过。
- 不做升星；材料培养仍是方向，本轮不实现材料经济、推荐/软降权、300人全库或人口/敌人曲线重做。
- 只在 main；保留已有未提交修改；不提交/推送、不接触真实玩家存档。

## 实现结果

- 正式菜单/结局的新局入口改走 `BeginOpeningRecruitment → ToggleOpeningHero → ConfirmOpeningRecruitment`，返回或继续同一草稿不重抽；选人/确认均先保存再发布。确认为首战 Combat 的待备战状态，必须由玩家点击开始战斗。
- `OpeningRecruitmentDto` 是活动征程v6的可空扩展，候选与勾选为不可变数组；现有无该字段的征程照常载入。空名册只在经过严格结构和资格校验的开局阶段合法，其他节点无法提前进入。坏草稿、写入失败不静默重置。
- 本次开局从征程池取得资格，不受旧账号仅解锁两名限制；账号记录仍保留。正式目录和独立英雄场景没有删减，其他英雄继续可用于实验室，旧名册和旧机会按既有契约保留。
- 普通招募与兼容候选查询共用先阶后人的确定性抽样，所有生成结果仍执行普通去重；普通招募保持最多3选1。开局与招募卡片显示“阶”，不显示为星级。既有单选开局API仅保留测试/工具兼容，正式导航不调用。
- 开局屏复用共享英雄详情组件；六张候选卡支持鼠标/键盘选择与取消，勾选/数量/姓名有非颜色提示，确认按钮固定在页脚。共享详情仅用现有摘要格式器清除测试稿前缀，未改英雄技能/数值。
