## 生命周期交接结论

- BC07 燃烧兑现按绝对到期 tick 和剩余周期计划计算，消费取消对应已排队但未执行的跳伤收据；到期 tick 可结算最后一跳，避免因单位行动先后额外多算。生命周期 Agent 的绝对到期／消费收据实现已整合，`ExecuteStatusEffectNow` 已接入 `TryClaimPeriodicInvocation`，领取周期收据后才执行伤害。

- HC26 使用同一 runtime id 延迟返场，保留本战历史／限次，只重授永久被动；无合法落点则等，受全战 MaxTicks 约束。初始队伍的待返场非临时身份参与终局资格，临时体和临时倒戈不扩大名册。
- 吞食只消费存活同队临时体，发布 Consumed 死亡供明确读者触发，不制造攻击／巨额伤害／敌方击杀；仅转指定数值。敌尸排除 Boss、已用及待返场身份，成功生成固定产物，空间或数量不合格时不支付法力。
- 缚心引导持续检查原目标与范围／视线、来源队伍／存活／行动能力，完成才临时切队，到期或来源失效还原；不重播开场。切队撤旧广播并重算羁绊，`CancelAllegianceProjectiles` 已接线取消相关在途弹；同 ID 返场／切队的 presenter 重建已接入。报告 UI 已按初始队伍保留归属，读取 `ActiveTicks` 扣除死亡等待。
