# 内容基础能力验收入口

## 当前边界

本轮按用户要求不自动试玩、不启动整局战斗或真实存档迁移。下面的 smoke 是已编写的隔离契约入口，是否已编译/执行以 `work-items/active/content-system-foundation.md` 为准；存在文件不等于行为通过。

## 独立契约入口

| 入口 | 保护的行为 |
| --- | --- |
| `tests/ContentPrimitiveContractSmoke.tscn` | 有界公式与循环拒绝、缺失上下文拒绝、编译快照不随资源编辑改变、目标范围/标签/生命比例/数量筛选、效果来源与独立使用额度、法强/魔抗作者入口 |

这些入口应使用测试构造或内存存档，不改生产的英雄/装备/遗物资产。原有 AbilityStatusContractSmoke 的被动样例改为合法常驻状态，不能继续把瞬时操作当成已支持的被动语义。

## 玩家正式流程观察点（待验收）

1. 招募、商店与战后奖励仍显示原有英雄动画肖像/装备卡。混合选项顺序稳定，鼠标悬停及键盘聚焦能查看完整条件、代价、概率和失败结果。
2. 战胜后不领奖退出，再继续：应恢复同一奖励机会；领取/跳过之后不得再次领取。奖励成功后的装备分配仍可用。
3. 休息/事件选择的全部收益与节点推进应同时生效；使用隔离故障存储拒绝保存时，机会和资源都保留。
4. 合成技能/装备/羁绊配置触发与撤销后，实际属性和伤害事实应对应变化；看得到说明不等于触发已执行。
5. 旧 v5 非战斗待决存档如无法证明已领奖状态，应明确拒绝并保留原件；不要为了验证去覆盖真实玩家存档。终局保存失败应停留可重试状态。

不要求本轮做多分辨率截图扫查、整局自动推进或真实玩家数据故障注入。
