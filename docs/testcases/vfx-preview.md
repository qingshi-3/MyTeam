## 动画取证入口
火球轰击使用 `--effect=firefall`，采样 168 帧；`fireball-lob-final-frames` 和 `fireball-lob-reduced-frames` 分别记录正常播放及浅底减少动态。已查看上扬、顶点、下落、爆发和烟灰关键帧；`fireball-lob.gif` 为正常速度录制。旧 firefall.gif 保留作比较。
持续播放回归加 `--effect=shield --continuous`：540 帧持续驱动预览控制器与播放器，不注入受击/结束事件。用于检查原 4 秒重播边界，不用有限 GIF 的首尾循环代表引擎持续效果。
使用同一测试场景，用户参数 `--motion <输出目录>`：加载真实 `VfxPreview.tscn`，默认撕裂采样 72 帧；`--effect=burst` 采样 96 帧，`--effect=shield` 采样 300 帧，每帧 1/60 秒。护盾在 2 秒受击、4 秒破裂（`--normal-end` 改为正常结束）。另支持 `--light`、`--reduced`。选择效果由测试程序发出列表信号；这是渲染取证，不能视为真实输入验收，不运行战斗。

本次输出位于 Codex visualizations 的当前任务目录：`rend-normal.gif`（正常速度）、`rend-slow.gif`（0.25×）、`rend-reduced.gif`（浅底减少动态）。已检查关键帧，正常速度审美仍待用户验收。

新增 `burst-layered.gif` 与 `shield-layered.gif`。冲击先看主波是否快速推出、粒子是否飞出，随后是否有较淡回波继续外扩；护盾先观察绕行，光带应从亮前景转入暗后景，盾体纹理保持稳定，再试受击与结束。静态盾体与轨道不是同一张旋转图片。

## 用户验收
最新光效补充：两刀外围有随锋面移动的暖色柔光，交点亮光稍强；刀身细节和两刀节奏应保持，尾迹结束后无悬浮光团。减少动态同时减弱光效强度。录制 `rend-glow.gif` 保留正常播放时序。
1. 主菜单进入“特效预览室”，选择交叉撕裂，先看 1×：第一刀左上向右下，约 0.09 秒后第二刀右上向左下；交叉短暂成立，随后各段沿原方向衰退。交点短亮、少量碎屑飞离，不应整张 X 摇摆。角色参照以身体锚点对齐。
2. 调 0.25×，暂停并使用“单步 1/30 秒”：亮锋应沿弧线推进；已经挥过的部位先变暗，碎屑各自移动。暂停等待时所有层冻结。
3. 切换浅色背景，检查边缘和角色遮挡。启用减少动态后刀痕保留显隐、停止行进，碎屑停止位移；结束仍正常清理。
4. 范围冲击应有主波和三圈较淡回波，在淡出时继续外扩，不出现旋转刀片。治疗应是随机大小的绿色加号，各自上浮淡出。能量弹保持原样。
5. 守护屏障外围绕中心转动、内层稳定；开启循环并连续观察超过 8 秒，不能闪灭、重新渐显或跳回初始轨道。分别试受击、正常消退、护盾破裂，结束后无残留且不会自动复活；点击重播才能重新出现。
6. 火球轰击：先看 1× 从施法者上扬抛出、转向下落，焰体应有暗红沟壑/橙焰/局部亮核，尾迹沿历史弧线逐段收细。接触后火焰波向外推出，烟灰正立膨开。暂停/单步检查落地衔接；半径滑杆只改变爆炸范围，距离滑杆改变投掷路程。当前是共享目录中的视觉样板，预览不进行伤害计算，尚未绑定正式技能。
