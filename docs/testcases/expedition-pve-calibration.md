## 首次执行发现的接入问题

森林复制原先只在能力实验中预注册十二名单位，正式战斗准备未注册 `OpeningCopy` 按成员身份隐式引用的单位定义。正式六人森林阵容开战因此报 `Missing clean clone profile`。现由共享战斗准备器从已激活复制羁绊的成员所属单位读取干净作者定义，保留原复制效果与数值，不继承原体的永久成长或装备修饰。

`tests/ExpeditionOpeningCopyContractSmoke.tscn` 验证正式准备路径、全部潜在复制成员的定义、原体额外属性不进入复制模板、复制体独立状态／临时身份／完整法力技能，以及不增加羁绊人数、两森林不触发。2026-10-06 构建为 0 警告／0 错误，专项输出 `EXPEDITION_OPENING_COPY_CONTRACT_OK`；三个种子实际选中 U11／U16，两者执行复制体断言，U17 的干净模板和技能定义也均已检查，不宣称本专项随机抽中了全部成员。

证据：`outputs/expedition-pve-20261006/build-verified.log`、`opening-copy.log`。初次准备失败及修复前复制异常分别保留于 `run.log`、`run-final.log`。最终批次使用独立 `verified/` 目录，保留前两次未完成批次作为问题证据。
